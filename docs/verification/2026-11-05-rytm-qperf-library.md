# Analog Rytm MKII: QPERF 0.2.0 in the library — 5 November 2026

Nathaniel Pavel's (@npp1993) QPERF, in `_submissions/` since #1105 (0.1.0-experimental), moves into the library as 0.2.0-experimental with the quick perf rec: performance moves recorded in LIVE RECORDING, applied to the pattern with RECORD + YES and cleared with RECORD + NO. Its source-only OS 1.74 package is pinned in `sdk/imports/elekloader-qperf-2026-11-05.json` (commit `59065954`).

- **Build:** `scripts/build-elemod-isolated.sh` in `modwerk-source-tools` (image `8f3b70d4…`, from `sdk/build/Dockerfile`) from a clean checkout of `3afad2ce`, whose module source the pinned commit carries unchanged (rebuilt on 6 November 2026 after the idle early return; the first build was from `3485d5e3`). The export reproduces with `package-elemod-recipe.mjs --check`, and `verify-elemod-release-exports.mjs` reproduces the 42 current exports from that build.
- **Package:** `qperf-0.2.0-experimental-os1.74.elemod` `37ea0357…df11`, fetched into the vendored catalogue through its pin by `npm run elekloader:update -- --overlay`.
- **Memory:** 17,824 bytes of the shared mod area by the linker's `ramSpare` with the vendored core-ar2 0.7 (alone 118,944, with QPERF 101,120); the quick perf rec's arrays are 6,912 of them.
- **Linking:** `planBuild` plans it beside Live Rec Retrig Fix and Temp Save (`src/engine/elekloader/digi-build.test.ts`).
- **On a unit:** the author's Analog Rytm MKII passed the quick perf rec's test plan on QT07 and QT08 (QPERF alone, with a debug trace over USB MIDI, since removed from the source) and, on 6 November 2026, ran QL19, the code before the idle early return: RECORD + YES/NO in each recording mode, a take and its apply with lock trigs on an empty track, as [TESTING.md](../../sdk/analog-rytm-mkii/modules/qperf/TESTING.md) records. This package's bytes have not been flashed from the site, and no browser build from a stock OS file ran here.
- **Idle CPU:** measured on the author's unit with a private telemetry base, in the author's 16-module set, sequencer stopped: the audio handler took 8.7 us a block before the early return and 5.1 us after (LF01, this source); removing QPERF lowered the idle block from 72.9 % to 70.9 %. On LF01 the QPER knob, pad locks and the quick perf rec work, as reported.
