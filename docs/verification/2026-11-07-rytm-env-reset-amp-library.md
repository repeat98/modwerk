# Analog Rytm MKII: Env Reset Amp 1.0.0 in the library — 7 November 2026

Iced-Cream's Env Reset Amp, in `_submissions/` since #934, moves into the library as 1.0.0 (same version, same code), with the author's OK in [#1291](https://github.com/repeat98/modwerk/pull/1291#issuecomment-6706064243). It is the elemod port of MrScruff's rytm-mods `0015-env-reset-amp`: SOUND SETTINGS > ENV RESET gains AMP and AMP+FILT, and with the amp bit set the amp envelope restarts from silence on every trig. Its source-only OS 1.74 package is pinned in `sdk/imports/elekloader-env-reset-amp-2026-11-07.json` (commit `f9953205`).

- **Build:** `scripts/build-elemod-isolated.sh` in `modwerk-source-tools` (image `28323550…`, from `sdk/build/Dockerfile`, unchanged since 5 October) from a clean checkout of `787719d2`, the move alone. The export reproduces with `package-elemod-recipe.mjs --check`.
- **Package:** `env-reset-amp-1.0.0-os1.74.elemod` `fadea586…e993`, fetched into the vendored catalogue through its pin by `npm run elekloader:update -- --overlay`. 52 bytes of `.run`, three sites, no `.bss`; its `.run`, sites and symbols are identical to rytm2_mods v1.2's release object `env-reset-amp-1.0-os1.74.elemod` (`881bcfed…40d1`), the object the module's `source-parity.json` links byte for byte.
- **Code:** unchanged from the submission; `sdk/imports/rytm2-mods-env-reset-amp-afd461d.json` names module-relative paths, so its hashes stand as recorded. The move adds the package, its pins and the release notes, and TESTING.md's library package section.
- **Linking:** `planBuild` plans it beside Filter Hz and Temp Save on the plain base (`src/engine/elekloader/digi-build.test.ts`).
- **On a unit:** the author's Analog Rytm MKII ran it in R8T2, C3A4, SXH4 and ERH4 (alone), all with core-ar2 0.3 or earlier, as [TESTING.md](../../sdk/analog-rytm-mkii/modules/env-reset-amp/TESTING.md) records. This package's bytes have not been linked against a stock OS file or flashed from the site, and it has not run on the Modwerk base (core-ar2 0.7).
