# Analog Rytm MKII: Ctrl All 1.2.0 in the library — 7 November 2026

Iced-Cream's Ctrl All, in `_submissions/` since #936, moves into the library as 1.2.0 (same version, same code), with the author's OK in [#1291](https://github.com/repeat98/modwerk/pull/1291#issuecomment-6706064243). It is the elemod port of MrScruff's rytm-mods `0014-ctrl-all`: hold TRK and turn a knob on a sound or TRIG page, and the same step goes to that parameter on all twelve sound tracks. Its source-only OS 1.74 package is pinned in `sdk/imports/elekloader-ctrl-all-2026-11-07.json` (commit `f16f4d99`).

- **Build:** `scripts/build-elemod-isolated.sh` in `modwerk-source-tools` (image `28323550…`, from `sdk/build/Dockerfile`, unchanged since 5 October) from a clean checkout of `4e85d714`, the move alone. The export reproduces with `package-elemod-recipe.mjs --check`.
- **Package:** `ctrl-all-1.2.0-os1.74.elemod` `1d0c2141…973c`, fetched into the vendored catalogue through its pin by `npm run elekloader:update -- --overlay`. 432 bytes of `.run`, 1 site, no `.bss`. Its `.run`, sites, symbols and relocations equal rytm2_mods v1.2's release object (`cc7d1b3c…bc7b`); where that object takes 14 runs (122 bytes) from the stock OS at link time, this package carries the bytes compiled from the source, as Filter Hz's package does.
- **Code:** unchanged from the submission; `sdk/imports/rytm2-mods-ctrl-all-afd461d.json` names module-relative paths, so its hashes stand as recorded. The move adds the package, its pins and the release notes, and TESTING.md's library package section.
- **Linking:** `planBuild` plans it beside Env Reset Amp and Filter Hz on the plain base (`src/engine/elekloader/digi-build.test.ts`).
- **On a unit:** the author's Analog Rytm MKII ran it in R8K4 and C3A4 (beside other rytm2_mods ports), SXH4 (beside the other five Modwerk submissions) and CAH4 (alone), all with core-ar2 0.3 or earlier, as [TESTING.md](../../sdk/analog-rytm-mkii/modules/ctrl-all/TESTING.md) records. This package's bytes have not been linked against a stock OS file or flashed from the site, and it has not run on the Modwerk base (core-ar2 0.7).
