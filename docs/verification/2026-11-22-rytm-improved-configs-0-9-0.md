# Analog Rytm MKII: Improved Configs 0.9.0-experimental — 22 November 2026

Nathaniel Pavel's (@npp1993) Improved Configs 0.9.0, formerly Silent Pad+Trig Settings (id `silent-pad-trig` unchanged): a fourth SEQUENCER CONFIG row, PAD LEAVES FX, makes a pad or TRIG 1-12 press that selects its track leave the FX track for that track's page, as TRK + pad does. Its source-only OS 1.74 package is pinned in `sdk/imports/elekloader-silent-pad-trig-2026-11-22.json` (commit `0a6f2d6f`), replacing 0.7.0's pin (0.8.0's package was committed but never pinned for the browser).

- **Build:** `scripts/build-elemod-isolated.sh` in `modwerk-source-tools` (image `3d0d46b0…`) from a clean checkout of `772ad2d8`, the source the package commit carries (`sourceTreeSha256` `2b66da21…c528`). Exported with `package-elemod-recipe.mjs`, reproduced with `--check`; `verify-elemod-release-exports.mjs` reproduces all 71 current exports from that build.
- **Package:** `silent-pad-trig-0.9.0-experimental-os1.74.elemod` `50960268…b785`, fetched into the vendored catalogue through its pin by `npm run elekloader:update -- --overlay`, which also removed 0.7.0's vendored copy. Earlier source-only packages and import records stay in `sdk/imports`.
- **Linking together:** `scripts/link-image.mjs` with the stock 1.74 main OS (kept outside the repository) links it alone on core-ar2 0.7 (PF01, PF02) and in the author's combined build PC01 (RC45's 17 modules). `planBuild` plans it beside the other Rytm library modules (`src/engine/elekloader/digi-build.test.ts`).
- **Emulator:** rytm-emu `2ac0f1f` on PF01/PF02 and PC01: with the row checked, pads, TRIG 3, RTRG + pad, FUNC + pad, silent selects and LIVE RECORDING leave the FX track; unchecked, or with nothing selecting, the FX track stays up as stock ([TESTING.md](../../sdk/analog-rytm-mkii/modules/silent-pad-trig/TESTING.md)).
- **On a unit:** on the author's Analog Rytm MKII, PC01 RAM-booted, as reported: from the FX track the MT and CH pads (silent selects) and TRK + pad brought up their track's page; FUNC + pad played without selecting with AUTO TRK SWITCH off. This package itself has not run on a unit, and no browser build from a stock OS file ran here.
