# Analog Rytm MKII: Improved AMP 0.1.0-experimental — 9 November 2026

Nathaniel Pavel's (@npp1993) Improved AMP is built as 0.1.0-experimental. On the AMP page HLD runs from no hold (0) to AUTO (127) and reads in steps at the current tempo and track speed; ATK, DEC and REL move in fine steps from 0.2 ms and read as times; OVR is finer at its low end and keeps its 0 to 127 number. ENV RESET gains AMP and AMP+FILT: a sequenced trig or retrig of such a sound is faded out over the 10 blocks (6.7 ms) before it, so the envelope restarts from silence without a click. It carries the envelope code first built as Improved Envelopes and the ENV RESET AMP of Iced-Cream's Env Reset Amp (MrScruff's rytm-mods 0015), which it replaces on a unit (`compatibility.conflicts`).

- **Build:** `scripts/build-elemod-isolated.sh` in `modwerk-source-tools` (image `39efd52a…`, built from `sdk/build/Dockerfile`) from a clean checkout of `740767f8` (first built from `632676a8`; the module's code is unchanged since, and the export is the same file). `verify-elemod-release-exports.mjs` reproduces all 62 current exports from that build.
- **Package:** `improved-amp-0.1.0-experimental-os1.74.elemod` `76fb70ef…6bfb`, exported by `scripts/package-elemod-recipe.mjs`; `--check` reproduces it. `.run` is 7,584 bytes and `.bss` 96 bytes; no mod storage.
- **Linking:** `scripts/link-image.mjs` with the stock 1.74 main OS (kept outside the repository) and the Modwerk base's plain variant (`1c14b6b0`) links the package alone as IA08, sha256 `0c5420f5…25c1`, byte for byte the image linked from the module's source and run in the emulator. It takes 7,868 bytes of the shared mod area (ramSpare 111,136, the base alone 119,004).
- **Emulator:** rytm-emu `2ac0f1f` on IA08: boot, the AMP page's DEC and HLD texts, ENV RESET's four values, the OVR reader's CV word at five knob values with every other register unchanged, and the pre-fade's mask before sequenced trigs, a pad roll's retrigs, swung trigs in the track's second event slot and the end of a retrig series ([TESTING.md](../../sdk/analog-rytm-mkii/modules/improved-amp/TESTING.md)). A host test runs the pre-fade's scan on 54 queue states.
- **On a unit:** this source, not this package's own image: on 9 and 10 November 2026 the author's automated USB test rig ran 25 cases on their Analog Rytm MKII with IL02 (`a569c9f5…284c`: this module's source on a development build of the base with a USB test link, loaded to RAM), all passing, as the rig's record reports ([TESTING.md](../../sdk/analog-rytm-mkii/modules/improved-amp/TESTING.md)): the screens, HLD in steps, sound lengths, OVR's curve and the FILTER times beside stock's, and the pre-fade across sequenced trigs, retrigs, swing, micro timing, sound locks, mutes and trig conditions. Not run: IA08 itself, a boot from flash, a power cycle, pads, an external clock. The first note after a RAM load was near silent in some boots, also without the module; cause not found.
