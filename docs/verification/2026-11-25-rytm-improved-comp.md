# Analog Rytm MKII: Improved Compressor 0.1.0-experimental — 25 November 2026

Nathaniel Pavel's (@npp1993) Improved Compressor enters the library at 0.1.0-experimental. On the COMPRESSOR page THR reads in dBFS where the compressor starts, following RAT, and MUP reads the makeup gain in dB; only those two value texts change. Its source-only OS 1.74 package is pinned in `sdk/imports/elekloader-improved-comp-2026-11-25.json` (commit `1673c217`).

- **Build:** `scripts/build-elemod-isolated.sh` in `modwerk-source-tools` (image `3d0d46b0…`, built from `sdk/build/Dockerfile`) from a clean checkout of `c26cef7d`, the source of the pinned commit. `package-elemod-recipe.mjs --check` matches the committed package byte for byte, and `verify-elemod-release-exports.mjs` reproduces the 72 exports already committed from that build.
- **Package:** `improved-comp-0.1.0-experimental-os1.74.elemod` `89fe8a3b…5f94`, 2,875 bytes. 652 bytes of code and tables in the shared mod area, no mod storage, no event subscription: one record in the core's parameter-text table.
- **Linking:** `scripts/link-image.mjs` with the stock 1.74 main OS (kept outside the repository) and the Modwerk base's plain variant (`2977431b`) links it alone into ICS1 (`d26771e9…`), the image the screenshots were captured from. `planBuild` plans it beside Filter Hz 1.3.1 and Improved AMP 0.1.2 (`src/engine/elekloader/digi-build.test.ts`).
- **Emulator:** rytm-emu `2ac0f1f`: THR 96 reads -36dB at RAT MAX and -18dB at 1:2, MUP 32 +20.6dB, THR 20 -110dB, stock's text in scene mode ([TESTING.md](../../sdk/analog-rytm-mkii/modules/improved-comp/TESTING.md)).
- **On a unit:** the author's Analog Rytm MKII ran the same source in the combined test image IC38 from RAM, by the author's automated rig, 25 November 2026: the same texts. The laws behind them were measured on that unit, THR and MUP on its drum voices and the ratios with a sine through AUDIO IN. This package's bytes have not been flashed from the site, and no browser build from a stock OS file ran here.
- **Reviews:** two independent reviews of the label code found no defect. An earlier build also drew a gain-reduction meter; it was taken out before release and is not in this package. A reviewer early in the work opened the source of Compressor Preview and Voice DAC against the author's clean-room rule for this module; nothing from them was used, and the later reviewers read only this module.
