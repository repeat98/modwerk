# Analog Rytm MKII: Main RMS 1.0.0 in the library — 7 November 2026

Iced-Cream's Main RMS, in `_submissions/` since #935, moves into the library as 1.0.0 (same version, same code), with the author's OK in [#1291](https://github.com/repeat98/modwerk/pull/1291#issuecomment-6706064243). It is the elemod port of MrScruff's rytm-mods `0009-main-rms`: on the compressor pages the VOL label draws inverted while the main output is louder than -18 dBFS RMS. Its source-only OS 1.74 package is pinned in `sdk/imports/elekloader-main-rms-2026-11-07.json` (commit `100f1d85`).

- **Build:** `scripts/build-elemod-isolated.sh` in `modwerk-source-tools` (image `28323550…`, from `sdk/build/Dockerfile`, unchanged since 5 October) from a clean checkout of `d93ad9a2`, the move alone. The export reproduces with `package-elemod-recipe.mjs --check`.
- **Package:** `main-rms-1.0.0-os1.74.elemod` `fe24c98b…6f4a`, fetched into the vendored catalogue through its pin by `npm run elekloader:update -- --overlay`. 264 bytes of `.run`, 3 sites, no `.bss`. Its `.run`, sites, symbols and relocations equal rytm2_mods v1.2's release object (`cbd69edb…5d54`); where that object takes 2 runs (16 bytes) from the stock OS at link time, this package carries the bytes compiled from the source, as Filter Hz's package does.
- **Code:** unchanged from the submission; `sdk/imports/rytm2-mods-main-rms-afd461d.json` names module-relative paths, so its hashes stand as recorded. The move adds the package, its pins and the release notes, and TESTING.md's library package section.
- **Linking:** `planBuild` plans it beside Filter Hz and Temp Save on the plain base (`src/engine/elekloader/digi-build.test.ts`).
- **On a unit:** the author's Analog Rytm MKII ran it in R8T2 and C3A4 (beside other rytm2_mods ports), SXH4 (beside the other five Modwerk submissions) and MRH4 (alone), all with core-ar2 0.3 or earlier, as [TESTING.md](../../sdk/analog-rytm-mkii/modules/main-rms/TESTING.md) records. This package's bytes have not been linked against a stock OS file or flashed from the site, and it has not run on the Modwerk base (core-ar2 0.7).
