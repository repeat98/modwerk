# Analog Rytm MKII: Filter Hz 1.3.0 — 15 November 2026

Filter Hz (id `filter-hz`, MrScruff's rytm-mods 0008-filter-hz as ported by Iced-Cream), 1.3.0: the FX track's DELAY HPF and LPF and REVERB FRQ, HPF and LPF show their frequency in hertz, worked out on the unit from the coefficient the stock DSP uses (no stock table copied), with LPF following a held trig's or scene's HPF lock. Their locked values get the 33-pixel box; LPF's box and locked text sit two pixels right so locked HPF and LPF keep a black column between them. Its source-only OS 1.74 package is pinned in `sdk/imports/elekloader-filter-hz-2026-11-15.json` (commit `8e5312f88`), replacing 1.2.1's pin.

- **Emulator:** every DELAY and REVERB filter value 0 to 127, turned and locked, reads the expected text in its box (FX02, 2,560 frames against 1.2.1); with HPF locked at 0 and 96, every LPF value locked beside it keeps both boxes apart with white around each text (FL03, 512 frames); FILTER FRQ's frames are byte for byte 1.2.1's (FZ80, core-ar2 0.3 + this source).
