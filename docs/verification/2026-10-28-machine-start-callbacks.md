# Octatrack source-machine START callbacks

Contributor: ex1010. Initial base revision: `8e6aecb142c1273e47ce2d9f235cebbd4f7cf6c9`.

A source machine can now contribute one separate versioned 16-byte START record and set `MODWERK_MACHINE_START`. The existing machine descriptor remains ABI 1/80 bytes (88 with the existing SETUP_PAGE extension). No module, FLEX handler-table cell, accepted audio engine or SPACE transport is changed here. Related to FRACT's machine migration in #926.

## Boundaries checked

The base selects a standard three-argument callback at the source-handler lookup, before argument pushes. Stock or Mute Modes still decides whether to dispatch that trig at `0x4000d498`. The shim reserves its stack frame, replays a guarded four-byte instruction from the user's OS and resumes after the whole six-byte patched span. It preserves d0/d1/a1, passes the track in d3 and leaves a0 as the selected handler. C preserves d2-d7/a2-a6. No selected fallback survives in global state when a trig is dropped.

Selection and invocation run within the frame interrupt. The loader publishes table rows under the existing lock/mask; a loader task cannot replace them during that interrupt. Existing Part/UI and paused-context retirement rules retain the outgoing image. This interface grants no asynchronous task or DSP lease.

Admission checks both the incoming encoded image and the completed reconstruction after relocations, stock copies and fills, before assigning an owner generation. The extension must name the same package's descriptor and an aligned address within its initialized image. It cannot overlap the complete descriptor, including SETUP_PAGE's extra eight bytes. Orphan, truncated, overlapping, wrong-version and missing-relocation declarations refuse. The reconstruction hook is read-only: it does not run retirement or other SWITCH side effects.

At dispatch, a missing/duplicate record or an unpaid DSP source refuses START and suppresses that owner's previous render until its next accepted START. Legacy and unowned tracks keep the exact selected fallback, including FM Synth. Known absent PROTECT signatures do not receive stock START with custom controls. Callback code must bound its own work; the interface adds no measured hardware deadline guarantee.

## START lifetime and SDK callback checks on 31 October

The owner authorised addressing both nonblocking review notes and chose to retain the package format with callback checking during SDK builds. Removal now clears `start_refused` for every track owned by the departing descriptor, while retaining refusals for descriptors still in the published machine table. The regression first failed on the earlier implementation, then passed: it covers eight refused tracks, unrelated table updates, partial removal, full removal and a replacement at the exact descriptor address rendering before any accepted START.

The linker preserves build-only ELF provenance before the final code/data image is flattened. A START callback must point to the entry of a sized, typed ELF function wholly inside `.text`, and its pointer word must have a self-relocation. The real C builder and mixed code/data assembly fixtures cover valid offset-zero code, data in `.text`, read-only data, a function-typed symbol in `.data`, BSS, interior/odd/out-of-image targets, missing relocation and missing ELF metadata. Assembly callbacks must supply `.type` and `.size`. These checks do not change the package ABI, the 16-byte START record or the 80-byte machine descriptor.

Installation still checks initialized-image bounds, alignment, ownership and relocation; it cannot distinguish code from data in an independently constructed flat package. ELF declarations are a packaging correctness check, not proof that authored machine code is safe or callable. No connected device is used or qualified by this update. Exact-head generation identities, checks, source-build results and advisory coverage are recorded in the PR description.
