# Analog Rytm MKII: Improved Machine Browser 0.1.0-experimental — 8 November 2026

Nathaniel Pavel's (@npp1993) Improved Machine Browser enters the library at 0.1.0-experimental. In the SRC machine list, UP, DOWN and the knobs A-H move the outline without loading; YES loads the outlined machine, NO changes nothing; FUNC + DOWN jumps to the next section, FUNC + UP to the top of this section, then of the one above. Its source-only OS 1.74 package is pinned in `sdk/imports/elekloader-improved-machine-browser-2026-11-08.json` (commit `a9e48321`).
