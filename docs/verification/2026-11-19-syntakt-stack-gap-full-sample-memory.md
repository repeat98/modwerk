# Syntakt 1.42 stack gap, full sample memory on a unit, 19 November 2026

The developer's Syntakt, results as reported after the run. The stack-gap build was flashed first, while every sample slot was empty. Transfer then filled all 64 slots until almost all of the 32 MB was in use. Track 8 played every sample slowly enough for each five-second sample to finish, and that recording matched the same pattern recorded on the stock OS. Phase cancellation in Ableton left no difference. No bug or error was reported. The audio is the same. The 84 bytes at `0x47fe0000` were not read. This run records that playback matched under that sample load. It does not prove those bytes remained. The earlier reload, with short kicks, is the [15 November note](2026-11-15-syntakt-stack-gap-sample-load.md).

- **Stock OS:** 1.42, used for the second recording. The file hash was not taken again for this run. The stock file in the 15 November note is `Syntakt_OS1.42.syx`, sha256 `ded3c59fdb909eb9e2c3307b30a486452c8fa6947b12c14e0ce35a187b7f37c1`. It stayed on this computer.
- **Build:** the modified 1.42 stack-gap OS, flashed before the samples were loaded. The screen version was not written down, and the flashed file was not hashed again. The stack-gap file in the 10 and 15 November notes is sha256 `9152335cd89d976849aa50b9393ff3eb3a04549b01e9202add7f9de4ddfc51af`.
- **Samples:** after the flash, every sample slot was empty. Transfer loaded all 64 slots. The developer reported the load as almost all of the 32 MB. Transfer's own used-memory figure was not written down. The sample names were not written down. Each sample plays for five seconds.
- **Pattern:** the same pattern for both recordings. Track 8 plays every sample. Track speed is 1/8. Tempo is 30 BPM. The track is split in two parts. The first plays the first 32 samples. The second plays samples 32–64. One blank step sits between samples, so each sample can play its five seconds.
- **Play:** no bug, error, or audio glitch was reported.
- **Compare:** the build and the stock OS were each recorded, then compared in Ableton by phase cancellation. No difference remained. The audio is the same. The recording length was not written down.
- **Not done:** a power cycle; reading the 84 bytes at `0x47fe0000`; the version string on the screen; hashing the flashed file again; Transfer's exact sample-memory figure; the steps that put the stock OS back; a full pass of the other factory functions.
