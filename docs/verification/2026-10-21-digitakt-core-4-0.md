# Elekloader Digitakt Core 4.0 catalog support — 21 October 2026

Added Elekloader's Core 4.0 pre-release pins (`core-v4.0`) for Digitakt mk1 OS 1.53 and 1.54 as a site-owned overlay. This core preserves the Core 3.0 interface and is compatible with DT-FM 1.2; the pinned upstream catalog remains unchanged.
- **Pins and packages:** the overlay updater downloaded both packages and verified their release SHA-256 values. `npm run elekloader:check` verified the complete catalog and vendored lock.
- **Selection:** the Modwerk planner resolves DT-FM plus Machine Pages to Core 4.0 for both supported OS versions. The `digi-build` regression test covers those selections. The worker test loads the catalog's pinned core and module assets.
- **User build (OS 1.54):** the owner reports that Modwerk successfully built and verified firmware with DT-FM alone and with DT-FM + Digi Health + Digi Utils. The latter composition was subsequently flashed for the hardware performance test below; flashing DT-FM alone is not reported. Build-log and output hashes were not provided.
- **User-reported performance test (22 October 2026):** on Digitakt I OS 1.54, with FAST audio enabled, the owner reports six simultaneous DT-FM tracks playing in a Modwerk build containing Digi Health, Digi Utils and Machine Pages before CPU usage reached 100%, as shown by Digi Health's System Info feature. The test project was not specified; this is a single reported observation, not a repeatable benchmark or a general performance guarantee.
- **Not tested:** hardware behavior, including sampling. Elekloader marks Core 4.0 as a pre-release; its release notes specifically say sampler input is not modeled by the emulator and needs hardware testing. Digitakt builds may choose Core 4.0 because it is the newest eligible core.
