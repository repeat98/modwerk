# Analog Rytm MKII: Control In Actions 0.1.2-experimental — 6 November 2026

Nathaniel Pavel's (@npp1993) Control In Actions 0.1.2 stops reading a jack in ACTION mode whose ACTION is OFF: the UI tick disarms it, and the `ev_render_out` handler is a two-byte test that calls the unchanged reading only while a jack is armed. A jack with an action is read as in 0.1.1, and actions play unchanged. Its source-only OS 1.74 package is pinned in `sdk/imports/elekloader-control-in-actions-2026-11-06.json` (commit `cd4f7750`), replacing 0.1.1's pin.

- **Build:** `scripts/build-elemod-isolated.sh` in `modwerk-source-tools` (image `8f3b70d4…`) from a clean checkout of `2354204c`, the source the package commit carries. Exported with `package-elemod-recipe.mjs`, which reproduces it with `--check`.
- **Package:** `control-in-actions-0.1.2-experimental-os1.74.elemod` `9c63f6c7…277d`, copied into the vendored catalogue (same bytes as the pinned file). 0.1.1's source-only package stays in `sdk/imports`.
- **Emulator:** CI12 (vendored core-ar2 0.7 + this source, `3e7e1661…`) in rytm-emu `2ac0f1f`: the three media plans replay, and the frames are byte-identical to 0.1.1's CI11, which reproduces the committed captures.
- **On a unit:** measured on the author's Analog Rytm MKII with a private telemetry base (audio block and each handler timed on DTIM0, sent over USB MIDI), RC31's 16-module set, sequencer stopped, both jacks in ACTION mode with ACTION OFF: the handler costs 3.60 µs a block with 0.1.1 (LR03) and 0.81 µs with this source (LR02). With an action set the reading is unchanged: 3.3 µs with 0.1.1 (LR01) and 3.6-3.7 µs with this source or with only another module changed (LR02, LR03), a shift put down to code layout. In LP01 (that set with this source and two other idle changes), the footswitch plays its action and plays nothing with ACTION OFF, as reported. Not run alone on a unit.
