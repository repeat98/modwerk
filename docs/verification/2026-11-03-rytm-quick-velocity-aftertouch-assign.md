# Analog Rytm MKII: Quick Velocity+Aftertouch Assign 0.1.0-experimental — 3 November 2026

Nathaniel Pavel's (@npp1993) Quick Velocity+Aftertouch Assign enters the library as a new module. Holding FIX or SAMPLER and turning a knob links that parameter to velocity or aftertouch in the sound's own four velocity and four aftertouch mod slots; while the key is held, stock's performance-lock drawing shows each linked knob's amount. Its source-only OS 1.74 package is pinned in `sdk/imports/elekloader-quick-velocity-aftertouch-assign-2026-11-03.json` (commit `fca5840f`). Downloads stay off (`DIGI_DOWNLOADS_ENABLED`).

- **Build:** `scripts/build-elemod-isolated.sh` in `modwerk-source-tools` (image `a9c5e7d5…`) from a clean checkout of `fca5840f`, the commit the pin names. The export reproduces with `package-elemod-recipe.mjs --check`, and `verify-elemod-release-exports.mjs` reproduces the current exports from that build.
- **Package:** `quick-velocity-aftertouch-assign-0.1.0-experimental-os1.74.elemod` `dd580f07…2c93`, fetched into the vendored catalogue through its pin by `npm run elekloader:update -- --overlay`. Compiled with the default `-O2` (build QM13: 3,540 bytes of code and data, 44 bytes of `.bss`).
- **Linking together:** `scripts/link-image.mjs` with the stock 1.74 main OS (kept outside the repository) and the Modwerk base for core-ar2 0.7 links it alone (QM13). Its `-Os` build QM11, 720 bytes smaller, linked beside Audio In FX, Chromatic Aftertouch Fix, Env Reset Amp, Filter Hz, Live Rec Retrig Fix, PHASER, Pipo Loop, QPERF, Quick Fill Trig Condition, Sample RATE, Silent Pad+Trig Settings and Temp Save (RC19), with about 800 bytes of the 128 KiB shared mod area left. QM13 itself (commit `ce238f07`) links beside Audio In FX, Chromatic Aftertouch Fix, Control In Actions (its CI02 code), Env Reset Amp, Filter Hz, Live Rec Retrig Fix, Pipo Loop, QPERF, Quick Fill Trig Condition, Sample RATE, Silent Pad+Trig Settings and Temp Save, without PHASER, with 340 bytes of that area spare (a test link by the combined-image builder). `planBuild` plans it beside Sample RATE and Silent Pad+Trig (`src/engine/elekloader/digi-build.test.ts`).
- **Emulator:** rytm-emu `2ac0f1f` on QM11 and RC19: links, the performance-lock display, the MODS FULL popups, SAMPLER's recorder, the FIX key, PERF and SCNE; on QM12 (the code review's FX-track fix) the same screens pixel for pixel and the FX track as stock; QM13 (`-O2`) repeats QM12's runs exactly ([TESTING.md](../../sdk/analog-rytm-mkii/modules/quick-velocity-aftertouch-assign/TESTING.md)).
- **On a unit:** the author's combined image RC18 (QM10 inside) passed velocity and aftertouch links, the display, kit save, reload and power cycle on an Analog Rytm MKII, as reported, RC19 (QM11 inside) passed, as reported, and QM12 alone (this package's source, built with `-Os`) passed the FX track and the same checks again, as reported. This package has not run on a unit, and no browser build from a stock OS file ran here.
