# Analog Rytm MKII: Quick Velocity+Aftertouch Assign 0.1.0-experimental — 3 November 2026

Nathaniel Pavel's (@npp1993) Quick Velocity+Aftertouch Assign enters the library as a new module. Holding FIX or SAMPLER and turning a knob links that parameter to velocity or aftertouch in the sound's own four velocity and four aftertouch mod slots; while the key is held, stock's performance-lock drawing shows each linked knob's amount. Its source-only OS 1.74 package is pinned in `sdk/imports/elekloader-quick-velocity-aftertouch-assign-2026-11-03.json` (commit `8199fcb6`). Downloads stay off (`DIGI_DOWNLOADS_ENABLED`).

- **Build:** `scripts/build-elemod-isolated.sh` in `modwerk-source-tools` (image `a9c5e7d5…`) from a clean checkout of the branch head that pins it. The export reproduces with `package-elemod-recipe.mjs --check`, and `verify-elemod-release-exports.mjs` reproduces the current exports from that build.
- **Package:** `quick-velocity-aftertouch-assign-0.1.0-experimental-os1.74.elemod` `dd0e9c09…07c3`, fetched into the vendored catalogue through its pin by `npm run elekloader:update -- --overlay`. Compiled with `-Os` (2,820 bytes of code and data, 44 bytes of `.bss`), which the full set below needs.
- **Linking together:** `scripts/link-image.mjs` with the stock 1.74 main OS (kept outside the repository) and the Modwerk base for core-ar2 0.7 links it alone (QM12) and, as QM11, 20 bytes smaller, beside Audio In FX, Chromatic Aftertouch Fix, Env Reset Amp, Filter Hz, Live Rec Retrig Fix, PHASER, Pipo Loop, QPERF, Quick Fill Trig Condition, Sample RATE, Silent Pad+Trig Settings and Temp Save (RC19), with about 800 bytes of the 128 KiB shared mod area left. `planBuild` plans it beside Sample RATE and Silent Pad+Trig (`src/engine/elekloader/digi-build.test.ts`).
- **Emulator:** rytm-emu `2ac0f1f` on QM11 and RC19: links, the performance-lock display, the MODS FULL popups, SAMPLER's recorder, the FIX key, PERF and SCNE; on QM12 (the code review's FX-track fix) the same screens pixel for pixel and the FX track as stock ([TESTING.md](../../sdk/analog-rytm-mkii/modules/quick-velocity-aftertouch-assign/TESTING.md)).
- **On a unit:** the author's combined image RC18 (QM10 inside) passed velocity and aftertouch links, the display, kit save, reload and power cycle on an Analog Rytm MKII, as reported, RC19 (QM11 inside) passed, as reported, and QM12 alone, this package's code, passed the FX track and the same checks again, as reported. This package has not run on a unit, and no browser build from a stock OS file ran here.
