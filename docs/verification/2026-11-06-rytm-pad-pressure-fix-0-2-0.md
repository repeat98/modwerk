# Analog Rytm MKII: Pad Pressure Fix 0.2.0-experimental — 6 November 2026

Nathaniel Pavel's (@npp1993) Chromatic Aftertouch Fix becomes Pad Pressure Fix at 0.2.0 (id `chromatic-aftertouch-fix` unchanged). During a retrig roll (RTRG held, or ALWAYS ON) a held pad's pressure now also reaches the sound's aftertouch and MIDI poly pressure; stock OS 1.74 sent it only to the roll's velocity, and with RTRG held and VEL.CUR set nowhere. Three byte sites, no new code. Its source-only OS 1.74 package is pinned in `sdk/imports/elekloader-chromatic-aftertouch-fix-2026-11-06.json` (commit `bb8e865d`), replacing 0.1.0's pin.

- **Build:** `scripts/build-elemod-isolated.sh` in `modwerk-source-tools` (image `8f3b70d4…`) from a clean checkout of `fd1a79cd`, the source the package commit carries. Exported with `package-elemod-recipe.mjs`, which reproduces it with `--check`; `verify-elemod-release-exports.mjs` reproduces the 41 current exports from that build.
- **Package:** `chromatic-aftertouch-fix-0.2.0-experimental-os1.74.elemod` `4c6c86c3…e81b`. 0.1.0's source-only package stays in `sdk/imports`.
- **Emulator:** rytm-emu `2ac0f1f`, stock, core-ar2 0.7 alone, PF01 (core-ar2 0.7 + this source, `c1b0e115…`) and the author's 16-module set with it (PP01): nine pressure cases (plain, RTRG held, ALWAYS ON, VEL.CUR OFF and set, normal and CHROMATIC pads) and PERF mode; details in the module's TESTING.md. Reviewed against the disassembly by an independent agent.
- **On a unit:** PP01 (`b939ae56…`) on the author's Analog Rytm MKII with USB MIDI logged: poly pressure in every roll case and on CHROMATIC's played notes; the roll still louder with pressure at VEL.CUR OFF; PERF pads follow pressure with RTRG held; no trigs from PERF pads in LIVE RECORDING. As reported. Not run alone on a unit.
