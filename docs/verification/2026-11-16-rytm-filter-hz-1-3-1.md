# Analog Rytm MKII: Filter Hz 1.3.1 — 16 November 2026

Filter Hz (id `filter-hz`, MrScruff's rytm-mods 0008-filter-hz as ported by Iced-Cream), 1.3.1: the functions in `src/fx-hz.c`, which run only in the UI task to format the FX pages' text, are marked cold, so GCC builds them for size and out of the hot code. `filter-hz.s` is unchanged and nothing on screen changes; `.run` is 1,545 bytes (1,745 in 1.3.0). Its source-only OS 1.74 package is pinned in `sdk/imports/elekloader-filter-hz-2026-11-16.json` (commit `3f4a519d1`, local until pushed), replacing 1.3.0's pin.
