# Syntakt 1.42 stack gap in the emulator, 6 November 2026

One run of the 1.42 stack-gap build in the local digiemu. The run reported that the user interface is live. The sixteen bytes at the SRAM tail and the first sixteen bytes of the stack gap were read from the snapshot saved at that point. `MW01` is the version string stamped into the container on the computer. It is not the mark. An emulator boot does not prove the gap survives a full sample load.

- **Stock file:** `Syntakt_OS1.42.syx`, sha256 `ded3c59fdb909eb9e2c3307b30a486452c8fa6947b12c14e0ce35a187b7f37c1`. It stayed on this computer and was not copied into the repo.
