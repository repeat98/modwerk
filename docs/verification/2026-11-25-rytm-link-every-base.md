# Analog Rytm MKII: the link's identity, load and log in every base — 25 November 2026

Every variant of the Modwerk base, release or development, now carries the USB link's read-only part: `ident` with the set identity (the CRC32 and length of the `.run` block, taken at the boot site), `load` (0x23), `diag` (0x22) and `log` (0x24), the log in the Octatrack's layout (version 2). Keys, pads, turns, the screen, memory reads, the remote YES and the RAM boot stay in development bases (`MODWERK_DEV`, `link-dev.s`). New release identities: send-bus **03902b3a**, voices **5f84b65d**, plain **096b0d40** (`base-binding.json`), each +3,848 B `.run`, +6,928 B (plain 6,924 B) `.bss`, +2 sites. Nathaniel Pavel (@npp1993).
