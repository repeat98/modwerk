# Analog Rytm MKII: Improved Performance 0.1.0-experimental — 21 November 2026

Nathaniel Pavel's (@npp1993) Improved Performance enters the library at 0.1.0-experimental. The audio interrupt leaves out work whose result is known (idle sample voices, sends at zero, a silent delay and reverb, modulation passes that would change nothing, parameters at rest, the compressor's control words, the unused USB audio input), and writes CPU or OVR into the bottom status bar's lower right corner while the audio load is near or over its limit. Its source-only OS 1.74 package is pinned in `sdk/imports/elekloader-improved-performance-2026-11-21.json` (commit `eb2899de9`).

- **Build:** `scripts/build-elemod-isolated.sh` in `modwerk-source-tools` from a clean checkout of `92efff617` (the evidence fingerprint commit), exported with `package-elemod-recipe.mjs`.
- **Package:** `improved-performance-0.1.0-experimental-os1.74.elemod` `7125b4c1…23ee`, fetched into the vendored catalogue through its pin by `npm run elekloader:update -- --overlay`.
- **Same image as the local build:** linked with the Modwerk base's plain variant and the stock 1.74 main OS (kept outside the repository), the package gives `aee6ea90…8b75`, byte for byte the image Modwerk's linker builds from the module folder.
- **Emulator:** a local rytm-emu with a cache model and an interrupt profiler, the interrupt run in zero time: the module alone on the plain base, and beside 17 other modules, against the same image with its sites written back to stock, identical engine state and DAC output in every one of about 69,500 blocks ([TESTING.md as merged](https://github.com/repeat98/modwerk/blob/94ffc1e8ec5127b5c7102cce3050cf7a11bbdfdc/sdk/analog-rytm-mkii/modules/improved-performance/TESTING.md)).
- **Linking:** `planBuild` plans it beside Improved Machine Browser and Temp Save (`src/engine/elekloader/digi-build.test.ts`).
- **On a unit:** the author's Analog Rytm MKII ran IP06 (this source but for two small CPU/OVR drawing changes made after it, beside 17 other modules on his development base): one pattern's audio load 72.1 % of the block against 85.4 % without the module; self-checking builds of the engine code counted 0 differences. This package's bytes have not been flashed from the site, and no browser build from a stock OS file ran here.
- **Retired the same day:** the owner asked to fold this work into the Rytm base firmware instead (repeat98/modwerk#1941); the module, its package and its pin left the library in the retirement pull request.
