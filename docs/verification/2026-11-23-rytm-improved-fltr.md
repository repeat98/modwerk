# Analog Rytm MKII: Improved FLTR 0.1.0-experimental — 23 November 2026

Nathaniel Pavel's (@npp1993) Improved FLTR enters the library at 0.1.0-experimental. FILTER TYP turns past PK to BW, a base-width band on the voice's analog filter: FRQ sets the high-pass edge, RES's knob reads WID and sets how far above it the low-pass edge sits, shown in hertz, and the FILTER graph draws the band. Its source-only OS 1.74 package is pinned in `sdk/imports/elekloader-improved-fltr-2026-11-23.json` (commit `bcd0947a`).

- **Build:** `scripts/build-elemod-isolated.sh` in `modwerk-source-tools` (image `3d0d46b0…`, built from `sdk/build/Dockerfile`) from a clean checkout of `40a6b359`, the source of the pinned commit. `verify-elemod-release-exports.mjs` reproduces all 72 current exports from that build.
- **Package:** `improved-fltr-0.1.0-experimental-os1.74.elemod` `4166dea7…f655`. 3,652 bytes of code, tables, names and variables, no mod storage.
- **Linking:** `scripts/link-image.mjs` with the stock 1.74 main OS (kept outside the repository) and the Modwerk base's plain variant links it alone into IFS2 (`9662fdd9…`) byte for byte, the image the screenshots were captured from, and beside Filter Hz 1.3.1 and Improved AMP 0.1.2 (IFP2, `28a23235…`). `planBuild` plans it beside those two (`src/engine/elekloader/digi-build.test.ts`).
- **Emulator:** rytm-emu `2ac0f1f`: TYP's turn to BW and its stop, the analog words BW sends, the graph and the texts, with stock's types compared ([TESTING.md](../../sdk/analog-rytm-mkii/modules/improved-fltr/TESTING.md)). The emulator's analog voices are stubbed, so it shows the controls and words, not the sound.
- **On a unit:** the author's Analog Rytm MKII ran the same source in combined test images from RAM (IFD2, IFC5), by the author's automated rig: the words and TYP as computed, and the band's edges measured with noise, top edges within about 3 % of WID, bottom edges 2 to 18 % above FRQ, as reported. This package's bytes have not been flashed from the site, and no browser build from a stock OS file ran here.
