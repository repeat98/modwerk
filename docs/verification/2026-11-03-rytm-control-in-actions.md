# Analog Rytm MKII: Control In Actions 0.1.0-experimental — 3 November 2026

Nathaniel Pavel's (@npp1993) Control In Actions enters the library as a new module. It opens stock's hidden footswitch mode in GLOBAL > CONTROL > CONTROL INPUT 1 and 2 as ACTION, so a footswitch or a 0 to 5 V gate on EXP/CV IN 1 or 2 holds or toggles the MUTE screen or live recording, or holds or latches FILL, with bars beside the menu and ACTION LEARN; NO in EXPRESSION LEARN and ACTION LEARN keeps the saved levels. Its source-only OS 1.74 package is pinned in `sdk/imports/elekloader-control-in-actions-2026-11-03.json` (commit `0ac3e87d`). Downloads stay off (`DIGI_DOWNLOADS_ENABLED`).

- **Build:** `scripts/build-elemod-isolated.sh` in `modwerk-source-tools` (image `0d02f26d…`) from a clean checkout of `73100dec`, the source the package commit carries, with the staging folder under the home folder (a local copy of the script; Docker Desktop could not mount `/var/folders`). Exported with `package-elemod-recipe.mjs`; `verify-elemod-release-exports.mjs` reproduces the current exports from that build, and Quick Velocity+Aftertouch Assign's committed package reproduces byte for byte with `--check`.
- **Package:** `control-in-actions-0.1.0-experimental-os1.74.elemod` `d480b544…466b`, fetched into the vendored catalogue through its pin by `npm run elekloader:update -- --overlay`. Compiled with the default `-O2` (build CI09: 3,260 bytes of code and data, 32 bytes of `.bss`).
- **Linking together:** `scripts/link-image.mjs` with the stock 1.74 main OS (kept outside the repository) and core-ar2 0.7 links it alone (CI09). Beside the author's full Rytm set it does not fit the 128 KiB shared mod area at -O2 (the combined-image builder's test links: CI03's code at -O2 844 bytes over, at -Os 60 bytes over, beside Quick Velocity+Aftertouch Assign at -O2). `planBuild` plans it beside Sample RATE and Silent Pad+Trig (`src/engine/elekloader/digi-build.test.ts`).
- **Emulator:** rytm-emu `c5732f0` on CI09 and its CE14 test build (which reads the jack from a poked word, as rytm-emu has no converter model): the menu and its names, both learns' YES and NO, the live bars, every action, an ACTION choice changed in the open menu, and screens pixel for pixel CI08's ([TESTING.md](../../sdk/analog-rytm-mkii/modules/control-in-actions/TESTING.md)).
- **On a unit:** on the author's Analog Rytm MKII, builds alone, as reported: CI06 passed every action, ACTION LEARN (then named LEARN LEVELS) with YES and NO, REVERSE DIRECTION and a power cycle; CI07 passed EXPRESSION LEARN's NO and YES. CI09 (this package's source, linked locally) then passed the bars, both learns' NO and a hold action, as reported. Not run beside other modules, and no browser build from a stock OS file ran here.
