# Analog Rytm MKII: Control In Actions 0.1.1-experimental — 4 November 2026

Nathaniel Pavel's (@npp1993) Control In Actions 0.1.1 reads EXP/CV IN 1 and 2 in the audio interrupt instead of stock's smoothed level once a UI tick, and plays an action on the UI task as soon as a panel key would: it posts a key message of its own to the UI task's queue, as stock's converter report does from the same interrupt, and takes it back in `ev_key` at order 10. A 10 ms quiet time after each edge takes a footswitch's bounce. Its source-only OS 1.74 package is pinned in `sdk/imports/elekloader-control-in-actions-2026-11-04.json` (commit `e6e53044`), replacing 0.1.0's pin.

- **Build:** `scripts/build-elemod-isolated.sh` in `modwerk-source-tools` (image `0d02f26d…`) from a clean checkout of `6ac1413b`, the source the package commit carries. Exported with `package-elemod-recipe.mjs`; Silent Pad+Trig 0.7.0's committed package reproduces with `--check`, and `verify-elemod-release-exports.mjs` reproduces the 35 current exports from that build.
- **Package:** `control-in-actions-0.1.1-experimental-os1.74.elemod` `290e39c7…a41e`, fetched into the vendored catalogue through its pin by `npm run elekloader:update -- --overlay`. Compiled with the default `-O2` (CI11: 4,098 bytes of code and data, 84 bytes of `.bss`). 0.1.0's source-only package stays in `sdk/imports`.
- **Linking together:** `scripts/link-image.mjs` with the stock 1.74 main OS (kept outside the repository) and core-ar2 0.7 links it alone (CI11). CI10, 152 bytes smaller, linked beside the author's 13-module Rytm set (base 441d96f7, unchanged store layout) and booted in rytm-emu. `planBuild` plans it beside Sample RATE and Silent Pad+Trig (`src/engine/elekloader/digi-build.test.ts`).
- **Emulator:** rytm-emu `2ac0f1f`, test builds reading a poked level (no converter model): from the input's edge to the action's KEYDISP call, 0.02 to 1.12 ms over ten UI-tick phases (CE16, CE17) against 4.2 to 49 ms for 0.1.0's code (CE15); every action, a bouncing switch and REVERSE DIRECTION ([TESTING.md](../../sdk/analog-rytm-mkii/modules/control-in-actions/TESTING.md)).
- **On a unit:** on the author's Analog Rytm MKII, CI11 alone (this package's source, linked locally) works great, as reported; no delay was measured. Not run beside other modules, and no browser build from a stock OS file ran here.
