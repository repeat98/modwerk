# Analog Rytm MKII: Improved AMP 0.1.2-experimental — 17 November 2026

Nathaniel Pavel's (@npp1993) Improved AMP (id `improved-amp`), 0.1.2: stock's hold compare (0x40109bc2..0x40109bd1) is kept from ending a hold by two byte sites that compare its counter with 0x7fffffff held in a0, in place of a `ptr` site to a 512-byte table of that value, so the module takes 8,716 bytes of the shared mod area instead of 9,228. The compare sets the same flags for every counter and HLD value; no change in behaviour. Its source-only OS 1.74 package is pinned in `sdk/imports/elekloader-improved-amp-2026-11-17.json` (commit `2accfcc61`), replacing 0.1.1's pin.

- **Build:** `scripts/build-elemod-isolated.sh` in `modwerk-source-tools` (image `3d0d46b0…`) from a clean checkout of `cd7cffd60`. Exported with `package-elemod-recipe.mjs` (`1e006bd5…d882`, `.run` 8,364 bytes, was 8,876: 0.1.1's `.run` with the table taken out, byte for byte); `verify-elemod-release-exports.mjs` reproduced all 68 current exports from that build, this one included.
- **Linking:** `scripts/link-image.mjs` with the stock 1.74 main OS (kept outside the repository) and the base's plain variant (`1c14b6b0`) links the package alone as IA17 (`32787aac…f6e0`, ramSpare 110,288; 0.1.1's package on the same base, IB11: 109,776).
- **Emulator:** rytm-emu `2ac0f1f`: IA17 against IB11 from cold boot with the same pad and HLD input give the same analog recording, every DAC word and the same voice states; the screenshot plans give the committed captures byte for byte. On a development base with the USB test link (IA18) the module's 8 rig cases pass against their references.
- **On a unit:** IA18 (this version alone on the development base with the link, CRC `8acf944e`) loaded to RAM on the author's Analog Rytm MKII by the automated test rig, with the author's go: with a looped sample on BD every hold measured as for 0.1.1 and 0.1.0 (`sound-hld`, `sound-hld-speed`), and nine more cases pass. The pre-fade's other cases ran without a ringing sound and did not measure it; its code is byte-identical to 0.1.1's (TESTING.md). Not run: the package flashed, the audio load.
- **Catalogue:** the vendored copy is the committed package, copied byte for byte, and `digi-build.test.ts` plans it beside Improved Machine Browser and Temp Save on the plain base.
