# Analog Rytm MKII: Silent Pad+Trig Settings 0.7.0-experimental — 4 November 2026

Nathaniel Pavel's (@npp1993) Silent Pad+Trig Settings 0.7.0: FUNC + TRIG plays the track at the TRIG page's VEL where TRIG keys are silent, and the LIVE REC row covers TRIG keys too, renamed SILENT P+T LIVEREC with its storage field `silent_pt_live_rec_on` (no migration: the rows start unchecked once). Its source-only OS 1.74 package is pinned in `sdk/imports/elekloader-silent-pad-trig-2026-11-04.json` (commit `dc69c943`), replacing 0.6.0's pin. Rytm downloads are on (`DIGI_DOWNLOADS_ENABLED`, since #1190), so the site builds it into a downloadable image; that download was not tried here.

- **Build:** `scripts/build-elemod-isolated.sh` in `modwerk-source-tools` (image `0d02f26d…`) from a clean checkout of `e68ef767`, the source the package commit carries. Exported with `package-elemod-recipe.mjs`, reproduced with `--check`; `verify-elemod-release-exports.mjs` reproduces the current exports from that build.
- **Package:** `silent-pad-trig-0.7.0-experimental-os1.74.elemod` `5d6d3785…fcbd`, fetched into the vendored catalogue through its pin by `npm run elekloader:update -- --overlay`, which also removed 0.6.0's vendored copy. 0.6.0's source-only package and import record stay in `sdk/imports`.
- **Linking together:** `scripts/link-image.mjs` with the stock 1.74 main OS (kept outside the repository) and core-ar2 0.7 links it alone (PS16). `planBuild` plans it beside the other Rytm library modules (`src/engine/elekloader/digi-build.test.ts`).
- **Emulator:** rytm-emu `2ac0f1f` on PS13 to PS16: every mode with both rows, one and none; LIVE REC record-path counters and audio; the rows' reset after the field rename; the new label's fit ([TESTING.md](../../sdk/analog-rytm-mkii/modules/silent-pad-trig/TESTING.md)).
- **On a unit:** on the author's Analog Rytm MKII, builds alone, as reported: PS14 passed FUNC + TRIG with VEL and LIVE REC's silent TRIG keys with FUNC + TRIG recording; PS16 (this package's source, linked locally) was flashed and reported all good.
