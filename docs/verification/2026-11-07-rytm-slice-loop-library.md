# Analog Rytm MKII: Slice Loop 1.0.0 in the library — 7 November 2026

Iced-Cream's Slice Loop, in `_submissions/` since #937, moves into the library as 1.0.0 (same version, same code), with the author's OK in [#1291](https://github.com/repeat98/modwerk/pull/1291#issuecomment-6706064243). It is the elemod port of MrScruff's rytm-mods `0012-slice-loop`: SLICE LOOP in the track menu fills an empty sound track with sixteen trigs, each locked to the next sixteenth of the sample. Its source-only OS 1.74 package is pinned in `sdk/imports/elekloader-slice-loop-2026-11-07.json` (commit `983fe2ec`).

- **Build:** `scripts/build-elemod-isolated.sh` in `modwerk-source-tools` (image `28323550…`, from `sdk/build/Dockerfile`, unchanged since 5 October) from a clean checkout of `b307442d`, the move alone. The export reproduces with `package-elemod-recipe.mjs --check`.
- **Package:** `slice-loop-1.0.0-os1.74.elemod` `8e9a7d2e…93bd`, fetched into the vendored catalogue through its pin by `npm run elekloader:update -- --overlay`. 752 bytes of `.run`, 1 site, no `.bss`. Its `.run`, sites, symbols and relocations equal rytm2_mods v1.2's release object (`b1b8f51b…1cf9`); where that object takes 46 runs (440 bytes) from the stock OS at link time, this package carries the bytes compiled from the source, as Filter Hz's package does.
- **Code:** unchanged from the submission; `sdk/imports/rytm2-mods-slice-loop-afd461d.json` names module-relative paths, so its hashes stand as recorded. The move adds the package, its pins and the release notes, and TESTING.md's library package section.
- **Linking:** `planBuild` plans it beside Env Reset Amp and Quick Trig Conditions on the plain base (`src/engine/elekloader/digi-build.test.ts`).
- **On a unit:** the author's Analog Rytm MKII ran it in R8T2 and C3A4 (beside other rytm2_mods ports), SXH4 (beside the other five Modwerk submissions) and SLH4 (alone), all with core-ar2 0.3 or earlier, as [TESTING.md](../../sdk/analog-rytm-mkii/modules/slice-loop/TESTING.md) records. This package's bytes have not been linked against a stock OS file or flashed from the site, and it has not run on the Modwerk base (core-ar2 0.7).
