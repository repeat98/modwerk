# Analog Rytm MKII: Voice DAC 1.4.0 in the library — 8 November 2026

Voice DAC enters the library as 1.4.0: rytm2_mods v1.4's elemod port (`01254ab`) of MrScruff's rytm-mods `0013-voice-dac` at his update 3a98e23. GLOBAL > AUDIO ROUTING > DAC SUM routes the voices through the DAC, and FILTER pressed twice opens DAC FILTER, whose page and knobs are contributed through core-ar2's page tables (`core_page_fns`, `core_params`, `core_view_pages`), not patched. Its source-only OS 1.74 package is pinned in `sdk/imports/elekloader-voice-dac-2026-11-08.json` (commit `58e19a0e`).

- **Build:** `scripts/build-elemod-isolated.sh` in `modwerk-source-tools` (image `6f8066eb…`, from `sdk/build/Dockerfile`) from a clean checkout of `d37f17f4`, the source of the pinned commit. The export reproduces with `package-elemod-recipe.mjs --check`.
- **Package:** `voice-dac-1.4.0-os1.74.elemod` `f6b2b459…edb6`, vendored through its pin by `npm run elekloader:update -- --overlay`. `.run` is 11,080 bytes, no `.bss`.
- **Parity:** linked with elekloader's released core-ar2 0.7 on stock OS 1.74, the package gives a main OS byte-identical to rytm2_mods v1.4's release object linked with the same core ([source-parity.json](../../sdk/analog-rytm-mkii/modules/voice-dac/evidence/source-parity.json)).
- **Linking:** on the Modwerk base's plain variant (`ba530f45`) it takes 11,108 bytes of the shared mod area (`ramSpare` 119,004 to 107,896). `planBuild` plans it beside Filter Hz on the plain base (`src/engine/elekloader/digi-build.test.ts`). It takes 39 of core's sound bits.
- **Emulator:** captures on the Modwerk base's plain variant with this package (VD14, `1ed68998…432e`), in analog-emu `4c07ed3`: DAC SUM in AUDIO ROUTING, DAC FILTER with TYP OFF, LP2 and LP1. The same input on stock 1.74 differs only from AUDIO ROUTING on.
- **On a unit:** VD4H (`d2b7c794…503a`: stock 1.74 + the Modwerk base's plain variant + analoghealth 1.3 for remote keys + this package) passed on the author's Analog Rytm MKII on 8 November 2026: DAC SUM, DAC FILTER on FILTER pressed twice, the knobs following TYP, BD's LP1 kept across SAVE KIT/KIT RELOAD and a hand power cycle, CPU 82.8-82.9 % while playing with DAC SUM on. The owner listened and reported "sounds as expected". Before that, this source passed on build V6H4 (core-ar2 0.6, 23 October 2026).
