# Draft profiles: Zoom MultiStomp

Drafts for [the proposal](../ZOOM_MULTISTOMP.md), in the shape it proposes:
they use a `vendor` field, platform `zdl`, the step set `format` / `load` /
`mods`, a release without stock files and the `pedal` art body, none of which
the current machine contract accepts. They are not read by
`machines:generate` and do not appear on the site. Once the owner agrees on the
contract, they move to `sdk/machines/<id>/machine.json`.
