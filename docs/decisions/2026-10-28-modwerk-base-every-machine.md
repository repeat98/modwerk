# A Modwerk base on every machine — 27 and 28 October 2026

- **The Rytm gets a Modwerk base (27 October 2026).** A contributor planning send effects for the Analog Rytm MKII asked whether the shared send bus should live in elekloader's core-ar2 or in a Modwerk-owned Rytm base. The owner chose Modwerk's, to keep everything central rather than depending on an upstream core for each hook. The base starts from core-ar2 0.3's source and owns the send bus, its pages, per-kit state and an FX list; each effect is its own module, installable beside the others. The plan follows the Octatrack beta (base, USB loading, web flashing), with the card or full-OS route as the fallback, and goes to the owner before any code.
- **Every machine gets the Octatrack's stack (28 October 2026).** Each unlocked device, and each one in the works, gets what the Octatrack has: the base firmware with hooks, the USB link and loading, base updates over USB, the MCP's device tools and an emulator where needed. The recipe goes where agents working on each machine will find it, so the stack scales the same way everywhere ([MACHINE_RECIPE.md](../MACHINE_RECIPE.md)).
- **What follows for hooks.** On the elemod machines a shared hook goes into the machine's Modwerk base in this repository; Modwerk no longer waits for an upstream core release to carry it. Until a machine's base ships, its current core remains the release authority.
