# Digitakt II modules

Each folder here is a library module for the Digitakt II on OS 1.17 and core 1.0: [Track Names](track-names/). Downloads stay off until the owner turns them on. The perform mods are pinned in the Elekloader build catalog for integration tests only.

Create one with `npm run module:new -- my-mod --machine digitakt-ii --author your-github-login`; see [the Digitakt II SDK guide](../../machines/digitakt-ii/README.md).
