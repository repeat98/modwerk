# Digitakt II modules

Each folder here is a library module for Digitakt II OS 1.17. The browser builds on Modwerk's core 1.1 base, which also supports [Track Names](track-names/). Downloads stay off until the owner turns them on. The Perform mods are pinned in the Elekloader build catalog for integration tests only.

Create one with `npm run module:new -- my-mod --machine digitakt-ii --author your-github-login`; see [the Digitakt II SDK guide](../../machines/digitakt-ii/README.md).
