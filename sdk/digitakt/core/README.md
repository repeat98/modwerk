# Digitakt core

The Modwerk core for the Digitakt: a small boot copier and the shared event bus every elemod module links against. [interface.json](interface.json) is its contract: the events, tables and exports it provides (interface 2.1), its claimed resources and its memory areas. `npm run modules:check` rejects modules that use anything the interface does not provide.

**Status:** provided by Modwerk's Digitakt base 5.0 for OS 1.53 and 1.54 ([sdk/machines/digitakt/base](../../machines/digitakt/base/README.md)), written from the interface's public documentation and behavioural specs (credited in the [Digitakt SDK guide](../../machines/digitakt/README.md)); no other core's source is copied. It grows the original [shared foundation](../../elemod/core/README.md) with DTIM0, the SRC machines and Machine Pages' contract, and every shipped mod links on it. Until a tester has run it on a unit, site builds keep the catalogue's core, and its memory area (`0x47BC0000–0x47C00000`, 256 KiB) is the base's; a set built on the catalogue's core 2.1 keeps 128 KiB.
