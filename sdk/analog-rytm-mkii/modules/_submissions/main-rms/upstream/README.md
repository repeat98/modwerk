# main-rms

Port of rytm-mods-src `mods/0009-main-rms` (MrScruff; `built`; its MANUAL says the display has been checked on the device there). Full usage: rytm-mods-src
`docs/MANUAL.md`, section 0009.

On the compressor pages (stock or comp-preview's), the VOL knob's label is drawn inverted while the main output is louder than -18 dBFS RMS (the louder side, about 300 ms average, off again 1 dB below).

## Sites

3 sites, the claims rytm-mods' registry makes for its default build
(`registry/allocations.toml`, owner `0009-main-rms`):

| addr | op | |
|---|---|---|
| 0x4012135e | jmp | `jmp main_rms_rms_scan` |
| 0x401e123c | ptr | pointer -> `main_rms_vol_knob_draw` |
| 0x401e1240 | ptr | pointer -> `main_rms_vol_knob_draw_alt` |

A detour is a `jmp` site over the whole stock instructions it displaces; the stub re-emits them
as in rytm-mods. Where rytm-mods patched the address operand of a `jsr`/`lea`/`move.l #`, the
site is elemod's `keep2` (the opcode word kept, the address the mod's). A pointer in a data
table is a `ptr` site.

## Changes from rytm-mods

- Generated by `tools/port_mod.py`. The code is unchanged; each label a site names gets a
  `.globl` alias carrying the mod id on the line before it, and the stub keeps using its own
  local labels.
- rytm-mods' default build params are fixed with `.equ` (`P_...`), as its build passed them;
  claims and code its diagnostic params select are left out.
- Every section the stub had in separate caves is `.text` here, one `.run` the linker places in
  the DDR mods area.

## Test (on a unit)

FX track, AMP: play a loud pattern - VOL inverts; turn it down or mute tracks - it clears.

## Results so far

- Built with elekloader at d17478b and m68k-linux-gnu binutils 2.42: `.run` 264 B,
  3 sites, 3 relocations; lint OK; links with core-ar2 0.1 and the other ports.
- Against rytm-mods-src's default build (all of its mods at their default params; "T2" below): the original stub, re-assembled
  as rytm-mods' build does, equals T2's caves byte for byte (.text 0x40137a48). Each of its 9
  labels was then disassembled in T2 and in the full build with every address named by its label: the
  instructions match.
- Every byte the full build changes in the OS is inside one of the ports' sites, every one of these sites is
  patched in T2 too, and the `bytes` sites write exactly T2's bytes.
- rytm-emu (3c4c42c), the full build (core-ar2 with all eleven ports): compressor pages while playing: the same screens as T2 (but comp-preview's SEQ label, above). The emulator's output never got loud enough to light the label, so the highlight itself is untested.
- Hardware: on an Analog Rytm MKII, 2026-10-14, in the full build (core-ar2 with all eleven ports): the VOL label lights up when the output is loud.
