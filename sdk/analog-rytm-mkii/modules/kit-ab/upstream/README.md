# kit-ab

Port of rytm-mods-src `mods/0010-kit-ab` (MrScruff; hardware-verified there). Full usage: rytm-mods-src
`docs/MANUAL.md`, section 0010.

NO + PLAY, as for a stock kit reload, now toggles between the edited kit and the saved one: the first press keeps the edits aside and reloads (KIT 1 RELOADED!), the next brings them back (EDITS RESTORED!). The KIT menu's RELOAD does the same. One set of edits is kept, 2.5 KB of heap from the first press.

## Sites

4 sites, the claims rytm-mods' registry makes for its default build
(`registry/allocations.toml`, owner `0010-kit-ab`):

| addr | op | |
|---|---|---|
| 0x400cd4ae | keep2 | the instruction's address operand -> `kit_ab_toggle` (stock `4eb9400af0d2`) |
| 0x400cd4d6 | keep2 | the instruction's address operand -> `kit_ab_kab_msg` (stock `487940255ea6`) |
| 0x400dd5de | keep2 | the instruction's address operand -> `kit_ab_toggle` (stock `4eb9400af0d2`) |
| 0x400dd5e6 | keep2 | the instruction's address operand -> `kit_ab_kab_msg` (stock `4879402578ae`) |

A detour is a `jmp` site over the whole stock instructions it displaces; the stub re-emits them
as in rytm-mods. Where rytm-mods patched the address operand of a `jsr`/`lea`/`move.l #`, the
site is elemod's `keep2` (the opcode word kept, the address the mod's). A pointer in a data
table is a `ptr` site.

## Changes from rytm-mods

- Generated by `tools/port_mod.py`. The code is unchanged; each label a site names gets a
  `.globl` alias carrying the mod id on the line before it, and the stub keeps using its own
  local labels.
- rytm-mods' default build params are fixed with `.equ` (`P_...`), as its build passed them;
  claims and code its diagnostic params select are left out.
- Every section the stub had in separate caves is `.text` here, one `.run` the linker places in
  the DDR mods area.

## Test (on a unit)

Edit a sound (e.g. BD DEC). NO + PLAY: KIT 1 RELOADED!, the saved value. NO + PLAY again: EDITS RESTORED!, your value.

## Results so far

- Built with elekloader at d17478b and m68k-linux-gnu binutils 2.42: `.run` 340 B,
  4 sites, 0 relocations; lint OK; links with core-ar2 0.1 and the other ports.
- Against rytm-mods-src's default build (all of its mods at their default params; "T2" below): the original stub, re-assembled
  as rytm-mods' build does, equals T2's caves byte for byte (.text 0x40137b50, .kab 0x401ba490). Each of its 11
  labels was then disassembled in T2 and in the full build with every address named by its label: the
  instructions match.
- Every byte the full build changes in the OS is inside one of the ports' sites, every one of these sites is
  patched in T2 too, and the `bytes` sites write exactly T2's bytes.
- rytm-emu (3c4c42c), the full build (core-ar2 with all eleven ports): BD TUN edited, then KIT menu (FUNC + PLAYMODE) > RELOAD twice: KIT RELOADED!, then EDITS RESTORED! with TUN back at the edited value (stock: KIT RELOADED! both times, TUN saved); all 14 screens pixel-identical to T2. NO + PLAY itself did not reach the reload handler in the emulator on any build, stock included, so that key combination is for the unit.
- Hardware: on an Analog Rytm MKII, 2026-10-14, in the full build (core-ar2 with all eleven ports): works as described (NO + PLAY).
