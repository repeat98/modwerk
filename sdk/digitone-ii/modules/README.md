# Digitone II modules

Each folder here will be a library module for Digitone II OS 1.12. There are none yet: the page builds Modwerk's base alone (beta), and how mods reach the musician is agreed with the owner with the first module (board, 19 November 2026). Downloads stay off until the owner turns them on.

Create one with `npm run module:new -- my-mod --machine digitone-ii --author your-github-login`; see [the Digitone II goal](../../machines/digitone-ii/GOAL.md) and [base](../../machines/digitone-ii/elekloader/README.md).
