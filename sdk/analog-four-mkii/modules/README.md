# Analog Four MKII modules

Library modules for the Analog Four MKII on OS 1.56 and core-a4 0.2 go here. There are none yet; unpublished modules wait in `_submissions/` until they have documentation, licensed source, captures, a resource record and hardware evidence.

Create one with `npm run module:new -- my-mod --machine analog-four-mkii --author your-github-login`; see [the Analog Four MKII SDK guide](../../machines/analog-four-mkii/README.md).
