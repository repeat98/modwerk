# Analog Four MKII modules

Library modules for the Analog Four MKII on OS 1.56 and core-a4 0.2 go here. There are none yet; a new module comes here with its pinned package and is live once merged, as on the [Analog Rytm MKII](../../machines/analog-rytm-mkii/README.md#create-a-mod).

Create one with `npm run module:new -- my-mod --machine analog-four-mkii --author your-github-login`; see [the Analog Four MKII SDK guide](../../machines/analog-four-mkii/README.md).
