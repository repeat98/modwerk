# Analog Rytm MKI modules

Each folder here is a library module for the Analog Rytm MKI on OS 1.74 and Modwerk's MKI base (core-ar2 0.7 at the MKI's addresses). The folders are the list: the library shows each with its release notes, and each folder's TESTING.md says what ran on which build. Add no list of modules or their history here, so two module pull requests never conflict on this file.

Create one with `npm run module:new -- my-mod --machine analog-rytm-mki --author your-github-login`; see [the Analog Rytm MKI SDK guide](../../machines/analog-rytm-mki/README.md).
