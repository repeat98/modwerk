# Digitone core

The Modwerk core for the Digitone: a small boot copier and the shared event bus every elemod module links against. [interface.json](interface.json) is its contract: the events, tables and exports it provides (interface 2.2), its claimed resources and its memory areas. `npm run modules:check` rejects modules that use anything the interface does not provide.

**Status:** provided by Modwerk's Digitone base 3.0 for OS 1.43 and 1.44 ([sdk/machines/digitone/base](../../machines/digitone/base/README.md)), written from the interface's public documentation and behavioural specs (credited in the [Digitone SDK guide](../../machines/digitone/README.md)); no other core's source is copied. It grows the original [shared foundation](../../elemod/core/README.md) with DTIM0, the voice, hold, MIDI CC, note-queue and key-LED hooks, the parameter slots, mod pages, project data, the Mod Menu and core_audio, and every shipped mod links on it. Its memory area is interface 2.2's 128 KiB (`0x47BE0000–0x47C00000`). Until a tester has run it on a unit, site builds keep the catalogue's core.
