# Digitone modules

Each mod is a folder here: `modwerk.module.json`, README, TESTING, licence, `src/` and `media/`. Create one with `npm run module:new -- my-mod --machine digitone --author your-github-login`. See [the Digitone SDK guide](../../machines/digitone/README.md).

## Module guides

| Module | Guide |
| --- | --- |
| [kitbank](kitbank/README.md) | One kit per bank, with per-pattern locks. |

The guides cover controls, access steps, a practical tutorial and the existing evidence limits. The frontend reads the same descriptions from each module's manifest.
