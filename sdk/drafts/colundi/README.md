# COLUNDI research draft · MICRO OSC

An independent monophonic track voice for testing absolute pitch under Octatrack sequencer control. The experimental instrument label is MICRO OSC. The public fixture asks whether two adjacent locked steps can differ by just 1 Hz.

## Signal and timing

On an accepted machine START, machine.c checks the current track's effective lane in either frame bank and samples the high byte of SRC B. Degree 78 selects 440 Hz and 79 selects 441 Hz. All other values clear that track. A new note resets its phase and attack. Each test tone holds for 4,096 samples, then releases over 128 samples. This short duration is intentional. A lock without START cannot restart the renderer. The base schedules the notes and splits each 16-sample frame at the event offset. The renderer writes dual-mono PCM to the source packer.

mono.c implements a Q32 phase accumulator and linear interpolation in a 257-entry Q15 sine table generated by make_sine.py. fixture.c rounds the two specified test frequencies at compile time for 44,100 Hz. The recovered engine also supports a second partial. The adapter keeps it off. SYNTIZ supplied the comparison renderer in the private experiment; importing its oscillator bank or depending on its module would add unused synthesis and controls. The shared machine registry, START table and stock audio chain already cover scheduling and routing. No shared base changes are proposed here.

## Reproduce

From the repository root, with Python 3.12, a host C compiler, Node 24 and the SDK's m68k-elf toolchain:

```sh
python3.12 sdk/drafts/colundi/test_pcm.py
python3.12 sdk/drafts/colundi/build.py /tmp/colundi.mwrm
npm run module:doctor -- --draft colundi
```

On a compatible emulated project, use MICRO OSC on T1 with SRC B locks 78, 79, 79, 78 on note steps 1–4. Put a trigless B=79 on step 5. Test the first PLAY immediately after editing and again with a preloaded pattern. Repeat STOP and PLAY. The stock-backed control has no custom DEG label yet. See TESTING.md before interpreting the results.

## Rights and scope

The original voice and new adapter use the included MIT licence. The mathematical sine table and synthetic two-tone fixture can be reproduced without tuning files. No third-party oscillator, sample, catalogue or firmware is bundled. COLUNDI is a research identifier. Permission for official branding or catalogue distribution is unconfirmed. Any future palette needs a documented source, redistribution terms and permission covering its intended use before inclusion.

Experimental prototype. Hardware qualification and release remain open.

## Maintainer feedback — DSP and resonator exploration, 23 November 2026

The ColdFire machine remains the reference for sequencer timing. Private DSP56300 tests produced both test pitches and measured a one-mode resonator on the same core. The resonator cost more per block and left a low-level tail. DSP source registration, whole-system load and an independent FX design remain open for review.
