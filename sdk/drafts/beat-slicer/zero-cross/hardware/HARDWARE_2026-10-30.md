## Observed results

The split-stereo fixture has LEFT crossings at each ideal anchor +9 frames and
RIGHT crossings at anchor -5. The first boundary remains zero. Its trim is
0–88,200 frames within 90,000 frames of audio, at 120 BPM and one beat per slice.

| Source / operation | Result |
|---|---|
| Flex stereo16, SNAP OFF, LEFT | Exact stock unaligned four-slice grid |
| Flex stereo16, SNAP ON, LEFT | Exact stock +9-frame boundaries, including end beyond trim |
| Flex stereo16, SNAP ON, RIGHT | Exact stock -5-frame boundaries |
| Flex stereo16, SNAP ON, BOTH | Exact stock -5-frame boundaries from the nearer channel |
| Static stereo16, SNAP ON, BOTH | Exact stock -5-frame boundaries |
| Flex mono16 long DC, NO during analysis | Cancelled after 26,432 pair reads; entire old table retained |
| Same DC, allowed to finish | Stopped at 65,536 reads; entire old table retained; completion status check **failed** |

Successful comparisons checked count/start/end/loop, all inactive rows and
unchanged source/settings. Every Flex before/after pair also verified the full
loaded decoded PCM against the unchanged reviewed WAV. Static used the verified
card file, observed browser selection, source binding and displayed file name;
no full streamed-PCM identity check is claimed. An attempted 24-bit Static file
reported a 16-bit loaded format, so it is not 24-bit qualification.

The strict comparator rejected an early RIGHT capture at the replacement prompt.
The applied result was captured afterward and passed. A BOTH capture with the
editor still open, after a rejected host command, is also excluded. Those are
host sequencing mistakes, not completed candidate results. The comparator now
requires CLOSED state for completed and cancelled results.

The module-only USB self-test passed its one installed module and reported
372 microseconds for the longest frame. It exercised no DSP effect and is not
proof of zero-crossing behavior or a worst-case frame bound.

## Findings and local corrections

UI cleanup calls cancel after processing an analysis result. Cancel previously
overwrote even a CLOSED editor's result with NO_CHANGE, including APPLIED and
ANALYSIS_LIMIT. The limit capture therefore has 65,536 reads and preserved
markers but status 8 instead of 12; its strict completion test remains failed.
The local base proposal now preserves a CLOSED editor's completed result.
Actual service/menu regressions check retained APPLIED, ANALYSIS_FAILED and
ANALYSIS_LIMIT through cleanup; all pass. This fix has not been rebuilt or
tested on hardware. The module package itself is unchanged.

The first full PCM capture also found a host-only bug: the helper assumed the
stock PCM arena address. It now uses the arena symbol from the identity-verified
running build, with page/range checks. A relocated-arena fixture rejects the old
assumption. Corrected full PCM checks passed on hardware. The seven preparation
tests pass, including the actual service/menu/search regressions; one separate
descriptor build fixture is skipped when the local ColdFire compiler is absent.
