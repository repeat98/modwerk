# LCD documentation captures

Captured from the LCD of an emulated Octatrack MKII (ot_emu) over its USB link, for documentation of this
module. The underlying Octatrack interface remains Elektron's copyrighted
interface; it is not relicensed as module source or supplied as UI assets for
reuse.

License identifier: LicenseRef-OT-UI-Documentation. These images contain no
firmware, executable code, factory samples or raw memory dumps. Provenance and
hashes are in capture.json.
