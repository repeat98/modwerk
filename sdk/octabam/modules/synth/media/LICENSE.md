# FM Synth media declaration

The seven `ot-*.png` files are original headless-emulator LCD exports of the
FM Synth 0.1.5 native image (MAIN OS `37661aee…`), made on 12 October 2026 with
Modwerk's capture tool and its capture plan, extended by a MIDI track's
CHROMATIC page (five are byte-identical to the 0.1.4 captures of 11 October,
whose plan descends from the captures made for Modwerk at the owner's request).
Credit: Modwerk contributors.
Their provenance, capture plan and hashes are in [capture.json](capture.json).
Only the rendered LCD images and sanitized metadata are submitted; firmware,
stock-containing runtime binaries, raw LCD/RAM dumps, cards, source project
fixtures and private logs remain local and temporary.

are submitted for module access/control documentation and reviewer evaluation.

The separate [thumbnail illustration](../presentation/thumbnail.svg) is
original Modwerk artwork, copyright 2026 Modwerk contributors, MIT under
[its licence](../presentation/LICENSE). It is not OT UI evidence.


## Audio preview

`audio-preview.mp3` contains only sound generated by FM Synth’s own MIT-licensed synthesis engine processed through the MIT-licensed Mini Verb engine. No external samples or private TR-909 reference recordings are included. The original source sound and final audio render are copyright 2026 Modwerk contributors and licensed under MIT (see the module `LICENSE`). The clip is an offline computer render recorded through Octemu, not a physical Octatrack recording. No firmware bytes, extracted code/tables, private card, raw memory dump or build image is included. Exact version, method, settings, post-encoding peak checks and file hash are in `audio-preview.json`.
