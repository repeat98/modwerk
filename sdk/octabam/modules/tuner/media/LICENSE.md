`ot-*.png` are original captures of the native Octatrack LCD, rendered in monochrome from the headless emulator for this module's documentation by the module author (Tim Hastie) with Modwerk's `scripts/capture-module-ui.py`. The underlying Octatrack interface remains Elektron material; no relicensing of that interface is claimed. Use is declared as `LicenseRef-OT-UI-Documentation` for review in this repository. Firmware, cards, samples, raw LCD planes and memory dumps are not distributed.
