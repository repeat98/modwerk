# Media rights

`ot-*.png` are original captures of the native Octatrack LCD rendered in monochrome for module documentation. Modwerk contributors created the capture plans; Zac Kyoti rendered these files from them for version 0.1.1. The underlying Octatrack interface remains Elektron material; no relicensing of that interface is claimed. Use is declared as `LicenseRef-OT-UI-Documentation` for review in this repository. Firmware, cards, raw LCD planes and memory dumps are not distributed.

`presentation/thumbnail.svg` is original Modwerk artwork under GPL-3.0-or-later.
