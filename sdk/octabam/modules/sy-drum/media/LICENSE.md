# SY DRUM media declaration

The `ot-*.png` files are original headless-emulator LCD exports of the native
SY DRUM 0.1.0 image (with FM Synth, which it needs), made with Modwerk's capture
tool (`scripts/capture-module-ui.py`) and the capture plan in
[capture.json](capture.json), which also carries their provenance and hashes.
Credit: Tim Hastie. Only the rendered LCD images and sanitized metadata are
submitted; firmware, stock-containing runtime binaries, raw LCD/RAM dumps,
cards, source project fixtures and private logs remain local and temporary.
