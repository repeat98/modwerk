# Model:Cycles modules

Each folder here will be a library module for Model:Cycles OS 1.13 on Modwerk's Model:Cycles base. There are none yet; the base is in development and downloads stay off.

Create one with `npm run module:new -- my-mod --machine model-cycles --author your-github-login`; see [the Model:Cycles SDK guide](../../machines/model-cycles/README.md).
