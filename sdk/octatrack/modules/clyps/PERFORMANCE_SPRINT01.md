# CLYPS private performance overlay · 25 November 2026

Experimental MKII / OS 1.40C implementation. Runtime source d9909f52f on module baseline 6b78afac9, contributor SDK and base 5c32cbacd. Original CLYPS sequencing work by Zac Kyoti and the OT Kyoti FW contributors. See PROVENANCE.md, LICENSE and LICENSE.kyoti.

## Performance controls

In the supported audio context, ARR opens the view last used (Row first). ARR again switches Row and Clip. Row shows eight tracks and five of sixteen row slots. UP/DOWN or LEVEL move the row; TRACK keys select the column through the stock, so the stock tab and CLYPS always name the same track (LEFT/RIGHT do nothing in Row). Clip shows sixteen sources for the selected track. TRIG launches directly. YES in Clip launches the focused source. In Row, hold TRACK first and press TRIG to launch that one cell. With a row focused, PAGE opens the setup popup. UP/DOWN or LEVEL choose Capture, Cell Source or Restore All. YES confirms. Capture stores the currently playing references at the cursor (including overwriting a previously defined slot). To edit one cell, choose its row and track before entering setup, select Cell Source, then TRIG or encoder A and YES. NO cancels setup. Restore All requires stopped transport. Rows live in RAM.

In Row, YES scans strictly forward from the last committed row. It ignores the cursor, undefined slots and repeat presses while a row is pending. At the end it leaves playback alone. A direct row launch moves the path on commit. A single-track override after a row commits keeps that position. STOP cancels an outstanding request. Initial state, confirmed project initialization and stopped Restore All start the path before the first row. Bank A only. An unsupported Bank suspends performance. The late project-load failure remains open.

NO returns to the native surface. At home, Native mode retains direct TRIG launch; a second NO exits it. With foreign sources, the selective edit lock applies: page keys, TRACK, Scene A/B (and Scene + TRIG), the crossfader and plain encoder turns reach the stock; trigs, encoder turns with a trig held, FUNC, REC, PATTERN, BANK and PART stay held, and a held gesture names the way out in the page bar. ARR reopens the remembered view; stopped YES restores home. Native sound and source editing, every popup, modifier ordering and every mode transition require separate qualification.

## Build and replay

Use the developer's private contributor SDK, a disposable GATE3 card and the MKII emulator specified in NATIVE_REPLAY.md. Run from the module checkout. Set D to sdk/octatrack/modules/clyps, BASE to the contributor checkout, OUT to a new private directory, OCTABAM to the Octabam source, and EMU to the MKII emulator. Keep firmware, cards and MWRM files outside Git.

```sh
python3.12 -B -m unittest discover -s "$D" -v
python3.12 -B "$D/generate_performance.py" "$BASE/sdk" --check
python3.12 -B "$D/build_candidate.py" "$BASE/sdk" "$OUT/clyps.mwrm" --performance --symbols "$OUT/module.json"
```

## Engineering decision and qualification

OS 1.40C stock audio modes documented by the synth port are TRACKS (0), CHROMATIC (1), SLOTS (2), SLICES (3), QUICK MUTE (4) and DELAY CTRL (5). The existing synth and quantizer use chromatic and selector gestures. The public octave hook handles a chromatic action. The public sequencer settings table contributes settings. Neither service extends the stock mode list or substitutes an audio lane source at a stock boundary. No evidence shows that hiding CHROMATIC or DELAY CTRL frees bytes, cycles or stack. Extending the native selector remains an upstream design question. The private overlay implements a reversible entry on ARR and leaves the stock mode table and persisted IDs intact. Stock mode LED rendering, persistence of selector changes, all MIDI paths and inter-module arbitration remain open. The earlier SRC list is outside this adapter.

The private builder requires ABI 9 and the candidate sequencer/panel mask. Public main 061fd547c includes PRs 2050 and 2062, and its event registry ends at 62. Runtime subscriptions 63–65 belong only to the contributor experiment. The regular draft descriptor and GNU-as unit expose the actual implementation to the official builder. The schema, declared UI claims and draft doctor pass with Track Solo declared incompatible because both own TRACK. No public catalogue entry. The public official procedure stops at step 3 on ev_seq_wrap. A stock-frame callback cannot select an independent pattern per audio lane. Future upstream adoption must express the capability in the official package and prove negative admission again.

On the contributor base, stock-composite comparison matched 624 events, 608 relative writes and 219 sampled states for the prepared eight-lane fixture. Three truncation controls were rejected by the unchanged grader. The UI replay observed capture R02/R05, direct T2 source selection, YES path advance, no implicit loop, override retaining position, pending cancellation and stopped restoration. After OFF the pool returned to 786432 bytes. These observations apply to the named package. Historical boundary, late-load and STATIC baseline failures remain separate. Hardware, listening, new-build MAIN/CUE capture, full-part edit coverage, power cycle, persistence across sessions and external clock remain unqualified.

The official public-base control refused the 66-entry package with code 257 (malformed hook table width) and preserved the pool, active count, owner count and three lifecycle callback heads. The equal-width feature-negative test remains a separate historical result. The new-build stock Arranger replay measured the same 336 calls and 336 writes before installation and after removal from a foreign T1 source. Native compositor captures, hashes, resource records and summary receipts are in evidence/performance-01 and media. GCC individual frames in bytes changed from 40 to 36 for key, 16 to 20 for encoder, and 188 to 120 for draw; tick and both sequencer callbacks remained at 8. These values exclude nested stack use.

For the Octabam declaration, regenerate performance_core.s with generate_performance.py against the contributor SDK. It follows the source-generated GNU-as unit pattern used by Arr Rows. The deployment contract must carry a feature check before a public or a private official-builder package can be qualified. Until then use only the explicitly named private build path for emulator reproduction.

A separate stock-control replay entered Native at home, changed AMP encoder A and restored the complete active Part hash. It compared the same T1 action, Scene A selection, crossfader positions 0/64/127/0 and the stock TRIG MODE path 0/1/0 with and without the adapter. The snapshots matched, playing and requested stayed home. Native T2 TRIG 2 then selected A02 and engaged the edit lock. The successful gesture sequence does not qualify arbitrary p-lock or source editing.

For cost.json use tests/native_profile.py with --performance-overlay and the same MAIN, symbol map and shelved card. Across six three-second windows there were zero measured skips and sheds. In the dense eight-lane A02 workload the 192 observed lane selections reached 162 emulator instructions and one boundary spanned 544. Stock maxima were 16 and 12. For the host-only draw comparison, compile tests/render_cost.c with cc -O2 and the SDK runtime/loader include directory, once with -DCLYPS_PERFORMANCE and once without. Each of seven batch means covers 20000 composed frames. Neither measurement is a physical frame price.

The timed stock popup interrupted Cell Source editing of R04 in a fresh native boot. ARR reopened, and a T1 override followed by R04 recall demonstrated that A01 survived the abandoned edit. OFF restored 786432 bytes. The same production adapter also refused MIDI, grid/live recording, pattern-chain and foreign-Bank entry in a host fixture and retained release ownership across popup takeover.
