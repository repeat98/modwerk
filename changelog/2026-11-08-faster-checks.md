Development: `npm run check` and `npm run pr:ready` are faster. The SDK suite (`npm run sdk:check`) runs each Python test file in its own process, on half the cores (at most four at a time), slowest of the last run first: 609 tests in 80 s instead of 203 s on an idle Mac, with the same tests and skips. `pr:ready` runs the check first and regenerates the catalogues only when it fails, instead of generating and proving every catalogue twice before a passing check. CI keeps ESLint's, TypeScript's, Vitest's and the SDK suite's caches between runs, so lint and typecheck redo only what changed. The build renders the module social cards at once instead of one after another.
