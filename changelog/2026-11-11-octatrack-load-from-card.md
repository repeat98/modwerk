Octatrack: a module set can now go onto the unit by card as well as over USB. Your Octatrack → Setup has Load from the card: it downloads your set as one file (MODWERK0.SET) with the same modules and versions a USB sync installs. Copy it to the card, switch the Octatrack off and on, and it starts with that set. It needs the Modwerk base on the Octatrack; card firmware without the base stays below it for now.
