Digitakt II, for module developers: the base can add new track machines after the stock ones (their own machine numbers, in the machine list, saved with kits). An added machine shows its own names on its stand-in's knobs, so saving, trig locks and live recording work as for the stock machine; it can name a knob's values too. The base sends an added machine's voices to the module's own sound-chip player, passes it the pattern's tempo and each track's speed, and puts the player into the build. Modwerk now has its own small sound-chip assembler, which checks the hardware's loop and register rules on every build. Not yet tested on a unit.
