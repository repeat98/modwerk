Digitakt II, for module developers: the base can add new track machines after the stock ones (their own machine numbers, in the machine list, saved with kits). An added machine shows its own names on its stand-in's knobs, so saving, trig locks and live recording work as for the stock machine; it can name a knob's values too. The base sends an added machine's voices to the module's own sound-chip player through a fixed slot per machine, so adding or removing a player leaves the base's code as it is; a machine without a player plays as the stock machine it stands for. It passes players the pattern's tempo and each track's speed, and lets other features read each transfer from the sound chip's side beside it. With no added machine installed, the base does none of this work. A player can send a short picture of what it plays back to the screen, and a module can draw it over the sample page's waveform while that page shows. Modwerk now has its own small sound-chip assembler, which checks the hardware's loop and register rules on every build, and the command-line image builder makes the same Digitakt II file as the website. Tested on a unit with a test machine on tracks 1, 9 and 16.
