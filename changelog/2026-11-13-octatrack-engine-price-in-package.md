Octatrack base (beta): a machine module that brings its own DSP engine (Analog BD) now carries its DSP price in its own package, so a new price no longer needs a new base. Until now the price sat in the part of the package the base trusts by hash, and every change to it meant rebuilding the base. Nothing changes for players yet: Analog BD 0.1.7 reserves the same DSP room as before (411 per voice and 3 per core, now one figure of 414 per voice), so DSP FULL appears where it did; a lower, measured price follows as an Analog BD update. The base refuses an engine that names no price or one taken from a model. Analog BD's package is rebuilt for the new base; Sidechain Compressor, Output Matrix, CC Map and Recorder Loop Fix keep their packages byte for byte and name the new base.
