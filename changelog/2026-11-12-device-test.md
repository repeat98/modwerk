Development: `npm run device:test -- <package>` is the agent's own test of a module on the unit. It runs the qualification exercise (alone on each DSP core, on every track while playing, knob sweeps, Part and bank switches, the load meters and loader counters) on one package installed as a trial that is rolled back at the end, so it keeps nothing and needs no `--keeps-ok`. It also reads the self-test and checks the inventory is unchanged, and its TESTING.md entry lists what it leaves for the developer at the unit. `/modwerk-fix-issue` now reproduces a report before the fix and tests the fix on the unit, `/modwerk-review-prs` can offer to test a pull request on the unit before merging, and `/modwerk-discord` takes its unit rules from `/modwerk-test-on-unit`.
