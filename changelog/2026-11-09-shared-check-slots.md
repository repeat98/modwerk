Development: `npm run check`, `pr:ready` and `sdk:check` take a slot on the computer before they start, so checks from several worktrees or agent sessions queue instead of running out of memory together, and fit their worker count to the free memory. `npm run slots` shows who holds them. `npm run lane` makes and reuses worktrees with shared `node_modules`, and `npm run lane -- prune` removes those whose work is all pushed.
