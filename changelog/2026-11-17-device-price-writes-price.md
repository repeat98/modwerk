SDK: `npm run device:price -- --write --base ID --scene TEXT <id>` now writes a module's measured CPU price into its manifest itself (`resources.cpuPrice`), keeps the readings in the module's `evidence/cpu-price.json` and takes the module off the pending list. `modules:check`, so CI and `pr:ready`, and `module:doctor` recompute a price from those readings and refuse one that differs, so a measured price is never typed by hand. Prices written by hand before keep their TESTING.md source. A `.mwrm` build of a published effect is now measured on a slot as well. A machine is still priced on a playing track (`npm run device -- do`).
