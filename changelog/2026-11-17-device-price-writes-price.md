SDK: `npm run device:price -- --write --base ID --scene TEXT <id>` now writes a module's measured CPU price into its manifest itself (`resources.cpuPrice`), keeps the readings in the module's `evidence/cpu-price.json` and takes the module off the pending list. `modules:check`, so CI and `pr:ready`, and `module:doctor` recompute a price from those readings and refuse one that differs, so a measured price is never typed by hand. Prices written by hand before keep their TESTING.md source. A `.mwrm` build of a published effect is now measured on a slot as well. A machine is still priced on a playing track (`npm run device -- do`). Adding a measured price no longer counts as a change to a published module, so it needs no new release. A pick that fails is no longer measured as the effect in use, and `--fx-name ID=NAME` names an effect the chooser shows under another name. First prices measured this way on an MKII: Tape Echo 7.7 % of a frame, Euclid 7.2 %, and 0 for BBD, E-Verb, LOFI2, Mini Verb, TapeHead and Ring SC, whose sound runs on the DSP. Then eleven modules that act on a key press, a menu or the sequencer: Track Solo 0.3 %, Direct Jump Kyoti, Tiempos and Tuner 0.1 %, and 0 for Apply Scene, Bar LED, Deja Vu, Preview Volume, Quantize Live Rec Toggle, Quantizer and Temp Save.
