Octatrack base update over USB: the new base no longer refuses to write itself. Every write on a unit was refused ("Device refused commit: backend", reported by a beta tester on 23 October 2026): before writing, the running base checked its bootloader copy and its packed code against its own RAM, which stock rewrites once it has started. It now checks the bootloader copy against stock 1.40C's digest and the packed code against a digest the base takes at boot, before stock reuses that memory. Reproduced and checked on ot_emu (the old base refused with reason 105); the NOR write itself has still not run on a unit. When a write is refused, the site now says so in words and leaves upload mode, and a power cycle still returns the Octatrack to its current base and modules.
