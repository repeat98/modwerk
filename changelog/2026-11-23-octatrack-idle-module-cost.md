Octatrack base 0.8.1: modules that are installed but unused cost much less CPU. Since 0.8 the base checked its whole table of module CPU costs again for every installed module, 60 times a second; it now checks the table once and keeps a copy. On an MKII with 16 unused modules the CPU meter read about 41 % stopped instead of 46 %, and the base's own work each UI tick fell from 1,412 to 247 µs.
