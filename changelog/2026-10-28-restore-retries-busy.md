Octatrack base (beta): after a power cycle, a kept module the base could not install at once because something was still starting up is now tried again every half second for up to ten seconds, and only then left out. Ring SC was the module this hit: after a power cycle it was sometimes missing from the restored set ("SOME MODULES FAILED") while a sync a little later installed it fine (beta finding 69). The unit takes USB requests only once the restore is done, so at most ten seconds later than before. A module refused for any other reason (no room, a clash) is still left out at once, and the card keeps the whole set so the next start tries it again. Not yet run through a power cycle on a unit: the cause of the refusal is not known, only that it passes within a minute.
