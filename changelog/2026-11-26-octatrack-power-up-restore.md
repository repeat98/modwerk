Octatrack base 0.8.2: a project no longer comes up empty at every start after a save. At power-up, stock refused the whole current bank when a single saved value needed fixing, so every Part and pattern of it read as empty until RELOAD, and again at the next start. The base now lets stock's own checks fix such values first, as loading the project from the card does, and the bank comes back with its machines and patterns.
