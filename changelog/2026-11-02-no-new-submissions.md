Developer tools: a new Analog Rytm module (or one for any Digitakt, Digitone or Analog Four) now goes straight into the library folder with its pinned package and is live once its pull request merges. `_submissions/` takes no new modules or changes, because nothing there ever reached the library, and `npm run check` says where the module goes instead. The Rytm guide's create command and release steps say the same.
