Octatrack base (beta): after a USB drop or another transfer failure has shut one DSP core's loader link for the boot, Sidechain, Analog BD and the key bus now say so instead of waiting silently until a power cycle. An engine that was not yet placed on that core reads STUCK, and a module that needs it is refused at install (Sidechain and Analog BD with a conflict, a key-bus reader as before), so the self-test names the failure. Engines already placed keep working, and a restart clears it as before. Seen once on a MKII (27 October 2026); checked in the host engine tests, not yet on a unit.
