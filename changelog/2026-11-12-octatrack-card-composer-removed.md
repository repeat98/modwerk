Octatrack: the card firmware builder's code is gone, not only its page. An Octatrack module now has to prove one thing to be listed: a current package for the Modwerk base, tested on a unit. The comparison with a native octabam build (`module:verify`), the card pair table (`modules:pairs`) and the card-only approvals are retired; the recorded comparisons stay as history. The developer tools (`firmware:download`, the MCP) no longer build an Octatrack firmware file.
