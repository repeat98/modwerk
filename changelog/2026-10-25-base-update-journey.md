Improvement: the Octatrack base update over USB (beta) says what will happen before it starts and shows where it is while it runs. The Octatrack now restarts once. Before the update, the dialog lists three stages in the order the unit will go through them. A unit that holds one copy of the base goes Send, Restart, Save: it starts the new base without saving it, and the new base then saves itself. A unit on the two-slot base goes Send, Save, Restart. The dialog also asks to save the project and stop playback first, since a restart loses what isn't saved, just as a power-off does. While the update runs, a stage bar marks where it is, with a progress bar while the base is sent. During the save, the status line turns into the warning not to switch off or unplug the unit. At the end the dialog stays open on "Done" until Continue is pressed; before, it closed the moment the unit came back. Fixed along the way: mid-update the Octatrack already runs the new base, so the dialog's title could switch to "Install the Modwerk base" and the old base number to the new one. The dialog now keeps what it began as. Checked with dialog tests on the simulated unit for both orders (the mid-update test fails without the fix). Not checked in a browser or on a unit.
