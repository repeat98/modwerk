Octatrack base (beta): module machines can own their SRC SETUP page over USB. The base drew SRC SETUP itself for every module machine and showed the stock FLEX/STATIC setup there, so VECTOR's page 2 (SEED, SPAN, OFST, ROT, RPT, DIR, a double tap on SRC) only existed in card builds (#972). A machine that sets the new `SETUP_PAGE` flag contributes a longer `ot_machines` record (`struct modwerk_machine_setup`) with its own page and encoder handler; machines without the flag, and every released package (POLY8, VECTOR 0.2.4, FM Synth, Analog BD 0.1.5), behave exactly as before, and a base without the flag reads the first 80 bytes as before. Checked in the registry's host test; not yet tested on a unit.
