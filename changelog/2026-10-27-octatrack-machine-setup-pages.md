Octatrack base (beta): module machines can own their SRC SETUP page over USB, and the double-tap machine chooser's cursor reaches every machine. The base drew SRC SETUP itself for every module machine and showed the stock FLEX/STATIC setup there, so VECTOR's page 2 (SEED, SPAN, OFST, ROT, RPT, DIR, a double tap on SRC) only existed in card builds (#972). A machine that sets the new `SETUP_PAGE` flag contributes a longer `ot_machines` record (`struct modwerk_machine_setup`) with its own page and encoder handler; VECTOR 0.2.5 uses it. Machines without the flag, and POLY8, FM Synth and Analog BD 0.1.5, behave as before, and a base without the flag reads the first 80 bytes as before. The double-tap TRACK chooser drew its rows from the list's scroll offset since #922, but stock's five UP/DOWN handlers still clamped the cursor to row 5, so with two or more machines installed DOWN stopped there; the base now owns those ten bytes and sets the clamp to the last row. Checked in the registry's host test and the emulator; VECTOR's page 2 on a MKII (development twin of this base).
