Development: commands for the common tasks, ready as soon as someone clones or forks the repository. `/modwerk-start` gives a new developer the overview: it asks which instrument and how they will test, checks the setup, and lists what they can do. `/modwerk-new-module`, `/modwerk-update-module`, `/modwerk-fix-issue`, `/modwerk-try-on-unit` and `/modwerk-pr-ready` walk through the matching guide. `/modwerk-review-prs` reviews the open pull requests, answers their authors where something must change, and gives the invoker the options for each. `/modwerk-maintain` runs the owner's daily pass. Each is a short list of steps pointing at the guide that holds the rules, so the guides stay the one source. The skills are committed twice, byte for byte: in `.claude/skills/`, which Claude Code loads, and in `.agents/skills/`, which Codex loads. `AGENTS.md` names them for every other agent and asks agents to open a developer's first session with the overview. `npm run check` fails when the list and the two folders stop matching. Checked with unit tests of the check and with `npm run check`. The site's Start developing prompts are unchanged.
