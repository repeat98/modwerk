Fix: an Octatrack C module that subscribes to no event, using only the core tick, draw, key and encoder hooks, can now be published for USB. `npm run octatrack:module-packages` used to stop on its package with "Not a supported published runtime ABI", because the builder made it ABI 4 with no name. It now goes out as ABI 8 with its id as its name on the unit, the form an event-subscribing C module already has, so the unit's inventory names it too. The published base's loader already reads that form, so no base update is needed, and every package already published rebuilds byte for byte.
