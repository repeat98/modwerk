Analog Rytm MKII: Modwerk now builds its own Rytm base from source, the first step of the Rytm's Modwerk base. Today it is core-ar2 0.7's source, copied unchanged with its provenance, and `npm run machine:base -- analog-rytm-mkii` builds it with the reviewed toolchain from your own OS 1.74 file and checks it against its recorded identity. It has the same sites and interface as irpina's release, so Rytm modules link as before. Nothing changes for players: the site still builds with irpina's release until the base ships with the send bus.
