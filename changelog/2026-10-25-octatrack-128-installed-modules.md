Octatrack base: up to 128 modules can be installed at once, up from 20. A sync that went past 20 installed modules was refused with "The Octatrack can’t run this module file.", because the base's saved-set check stopped at 20 rows and gave no reason. The module memory (768 KiB) and the loader already held 128; the set journal and the number of changes in one sync now match it. A set past the limit, or past the card's saved-set room, now says the Octatrack has no room for another module or not enough module memory. The site gives a big sync and its Undo 500 ms a changed module (10 s at least) instead of 10 s in total. Installed effects still run only on the tracks that pick them; modules with their own tick run while installed, so CPU load grows with them. Checked with host tests and site unit tests, and on the owner's Octatrack MKII over USB with base 77226ffc RAM-booted: 26 modules synced as one set, self-tested (all 26 intact, CPU peak 71 %) and undone in 6 s. Not yet checked on hardware: saving a set of more than 20 modules to the card and restoring it at startup.
