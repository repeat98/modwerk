Fix: module authors can release their own updates again, ports included (#1541). Two registry logins were not lowercase, so every author release stopped with "Pin each module author to an immutable GitHub account ID"; all keys are lowercase now. The registry now holds every Octatrack catalog module's primary author (12 were missing, among them the original authors of ported modules), and a test refuses an Octatrack catalog module whose `author.github` is not registered, so a first release registers its author. An author update may add an import record whose `root` plus file path stays inside the module's own folder (or its `sdk/octabam` copy), as ported Octatrack records are written; records without `root` keep the `modules/<id>/` rule.
