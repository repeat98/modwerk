Octatrack base 0.8.3 (development): an FX effect can change its DSP code while it plays, for effects whose sound is a program picked with a knob, like the Quadraverb's 90 factory programs. A module gives the base each program's code through a new table, `ot_dsp_effects`; for each track that runs the effect the base keeps two code areas in the DSP, writes the next program into the one the track does not run while it keeps playing, then switches the track over between two audio frames, so no frame ever runs half-written code. Going back to the program before costs no write. Nothing changes for any module that does not use it: no frame costs more, and every effect loads as before.
