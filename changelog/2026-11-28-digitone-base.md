SDK: Modwerk's own Digitone mk1 base, version 3.0 for OS 1.43 and 1.44 (`sdk/machines/digitone/base`). It implements the whole of interface 2.2: the twelve hooks, three parameter slots, mod pages, the Mod Menu, an output owner, and project data in one list shared with every writer, so modules that keep their own records in the project header (KitBank) keep them. Project save and new hook the stock routines' calls, which leaves KitBank's sites free: KitBank links on it on OS 1.44, where the catalogue's newest core refuses it. Its memory area is interface 2.2's 128 KiB. `npm run elemod:base -- digitone` builds it from source; `digi:link-all --core` now also links a given core on its own for an OS no mod ships for. It has not run on a unit yet, so site builds are unchanged.
