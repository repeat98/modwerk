Octatrack base 0.8.3: every frame costs about one point of CPU less. Sixteen times every audio frame the Octatrack looks up which Part is playing, and it read that from a slow part of its memory although the same value sits in its fast on-chip memory, written there at the same moments. The base now reads the fast copy. On an MKII the frame interrupt fell from 37.0 to 36.0 % on a busy pattern and from 29.8 to 28.8 % stopped; the sound and every value the DSPs receive stay the same.
