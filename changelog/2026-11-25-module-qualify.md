Development: `npm run module:qualify -- <id> --procedure DIR --base TEXT` writes a module's release record from its evidence. It reads the test procedure's record and `price.json`, the tested package, the perf:audit record and the screen captures. From them it writes `tests.qualification`, the measured gauges and the CPU price and instance curve, and computes `sourceSha256` last. Words a person has to stand behind are kept as written, or drafted and marked for the author to edit. `--check` and `module:doctor` report a stale `sourceSha256` with the command that refreshes it. `device:price --write` and the test procedure (`--price-base TEXT`) now write a draft's price and curve into `sdk/drafts/<id>` too.
