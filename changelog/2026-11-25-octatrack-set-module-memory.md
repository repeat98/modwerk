Octatrack: a module set that needs more module memory than the Octatrack has is now stopped before anything is sent, with how much it needs, how much to take out and its three largest modules: "This set needs 875 kB of module memory, and the Octatrack has 787 kB. Before, the sync went through, the Octatrack refused it and the site said only to remove a module, so people took out small ones and tried again many times.
