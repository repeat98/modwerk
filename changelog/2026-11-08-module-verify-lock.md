Development: `npm run module:verify` now takes a lock on its work directory (`~/.cache/modwerk-native`). A second run, for example from another worktree, waits until the first one is done. Before, each run replaced the shared copy of the SDK sources in that directory, so two runs at once could build with the other checkout's sources, or fail when a file disappeared. A lock left behind by a run that was killed is taken over.
