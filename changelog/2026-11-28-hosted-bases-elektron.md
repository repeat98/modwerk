Site: the Digitakt II, Analog Rytm MKII and Model:Cycles build panels offer Modwerk's prebuilt base once it is hosted, for a set with no modules while no OS file is chosen, wherever downloads are open for the machine. It downloads only after the risk and recovery ticks, and only an image whose identity is the base the page builds and whose size and SHA-256 match. Sets with modules still build from your own OS file. `npm run base:publish -- --machine <id>` builds and uploads these images for the owner.
