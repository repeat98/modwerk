Octatrack base: a USB Audio stream now counts in the CPU limit. While a computer records from the Octatrack or plays into it, every frame takes longer, and the base now knows: a module pick that would break up beside the stream is refused, and the CPU FULL box says USB AUDIO STREAM instead of PART IS BUSY. When a DAW starts on a pattern that no longer fits, its dearest machines pause with a USB AUDIO STREAM notice instead of crackling, and the room comes back as soon as the stream stops. Ships with the next base. A light pattern with one heavy machine picked before the stream starts can still drop a few of that machine's sounds once it does.
