Firmware builder: the linker that combines a core and its module packages into one main OS (layout, tables, relocations, module storage, the Octatrack's DSP areas and every check a set must pass) is now Modwerk's own (`src/engine/elektron/package-linker.ts`). Builds are unchanged: on the stock Digitakt 1.53 and 1.54, Digitakt II 1.17 and Digitone 1.43 and 1.44 OS it linked 304 random sets of the library's packages to the same bytes, map, tables and layout as the previous linker, and refused 638 others with the same messages (22,152 checks). The Analog Rytm MKII and Model:Cycles sets were not compared: no stock OS file for them here.
