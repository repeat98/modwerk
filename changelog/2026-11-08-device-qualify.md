Development: the Octatrack qualification run is `npm run device:qualify`, named in the module guide and the try-on-unit skill. It starts only with `--keeps-ok`, since each install and removal is a Keep that rewrites the card's kept set. It records each package's SHA-256 and can write what it saw as a TESTING.md entry (`--testing-entry FILE`). A pull request that gives a module a new version must name that version in its TESTING.md, and `module:doctor` says when a module's hardware record names a different image than the USB package that ships.
