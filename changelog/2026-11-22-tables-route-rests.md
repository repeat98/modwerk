Octatrack SDK: a table module's package now carries the detours its `runtime.json` marks `"rests"`. The tables route (`build.py --octabam-tables`, `runtime_units.compile_linked`, Mute Modes' route) dropped the list without a word, so the package's detours stayed patched while the module rested and kept their frame cost. It now marks them as the octabam route does and refuses a `"rests"` address that is not one of the module's own detours. `module:doctor`'s "cost at rest" line now reads the rest marks from the committed USB package of the module's version, not only from `runtime.json`, and fails when an address `runtime.json` names is not marked there. Every published package rebuilds byte for byte (`octatrack-module-packages.py --check`). Checked with `sdk/tests/test_runtime_units.py` and `scripts/module-cpu-price.test.mjs`: both new tests fail without the change.
