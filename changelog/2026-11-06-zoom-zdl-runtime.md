Zoom MultiStomp: Leemuzhko's own runtime for ZDL effects (the knob and OnOff handlers and the `Dll_` entry, MIT, written from the documented ABI) is vendored in `vendor/zoom-zdl-runtime/`, so effects can be built without the stock Zoom code every built effect carried so far. The `zdl` contract proposal records it and the limits its author measured (nine knobs, each knob's stored width, five-character labels, the load size). Nothing is listed or built from it on the site yet.
