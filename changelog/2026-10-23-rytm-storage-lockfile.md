Mod storage on the Analog Rytm MKII: each configuration now remembers where its last build put every module's stored settings, and the next build of that configuration keeps them there. Adding or removing a module no longer moves the others' data, so projects saved on the unit keep their mod settings after a rebuild. The configuration's JSON backup carries this layout too. Nothing changes for Digitakt, Digitone or Digitakt II configurations, and no library module stores settings yet.
