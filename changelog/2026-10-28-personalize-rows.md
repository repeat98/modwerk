Octatrack base: PERSONALIZE rows are a base table, `ot_personalize_rows` (hook index 38). Each row names the stock row it goes after, so MUTE MODE sits after PREVIEW WITHOUT FX, next to the other mute settings, as in the card build. Rows without a place go at the end, and LED BRIGHTNESS stays last on an MKII. Modules no longer grow stock's PERSONALIZE tables, so several modules with PERSONALIZE settings fit in one build, and a module that adds a row no longer needs a new base for each update.
