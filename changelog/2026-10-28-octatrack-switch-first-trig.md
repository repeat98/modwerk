Octatrack base (beta): switching a track from Analog BD (or another module machine that runs on a FLEX track) back to FLEX while the pattern plays no longer makes the first FLEX trig stutter. Each trig on the machine also started stock's FLEX voice, reading the machine's settings, and that voice kept going after the switch, so the first real trig cut it short or played over it as a short double hit. The base now stops that voice when a track switches between FLEX and a module machine, so the track stays silent until its next trig. Switches to or from STATIC and the other stock machines are unchanged. Checked in the host test; not yet tried on a unit.
