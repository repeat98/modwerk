SDK: the Analog Rytm MKII base gains digital voices (send-bus variant): a machine can render a voice's stream in its own code (hit detection, LEV, the quiet gate, a 3-bit type per sound with the SYNTH page's tap and label, and `ev_sound_applied`), with all four EMAC accumulators clear for it. `machine:base` now compiles the base with GCC's late-combine pass off and checks its code, as module builds do. The guide records the unit's EMAC timing, the per-block cache cost and the audio block's own load, and `tools/voice_rig.py` measures a digital voice on a unit against its host model.
