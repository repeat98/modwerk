Development: the checks now catch what reviewers asked for most often. A pull request's description must say what changed and answer the guides question. In CI, a contributor's module pull request opened from 9 November may not also change the base or a check that judges modules, and pr:ready says the same locally to everyone. In a pull request's CI run, a module, hook or migration the branch adds must be claimed on the agent board. A module may not reuse another module's thumbnail. A module new to the library has one release-notes entry, and its tested commit cannot be one already on main. The triage bot now counts pull requests under sdk/drafts as module pull requests, so one module pull request at a time applies to them too. A published package file that no package row names is refused, and the two left behind by earlier updates, LOFI2 0.1.0 and Sidechain Compressor 0.1.2, are gone from the site. A browser-builder record for a package built in this repository must name this repository as its source.
