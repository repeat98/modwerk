Fix: on the Octatrack base, a module trial that ended while one of the module's pages was open (Micro Timing's TRACK TRIG EDIT row, say) could no longer be undone, even after the page was closed: the unit stayed in recovery until a power cycle, and unplugging USB did not help. The base checks that no open page still uses a module before taking it out, and it counted the module's own change to the stock page as such a use, although taking the module out puts that change back. It now looks at the page as it will be once the module is out. While the page is still open the Undo still waits, so close it first; `npm run device -- recover` then finishes the rollback. Reproduced and fixed on an MKII running a development copy of the beta base with Micro Timing's trial package, and in a host test.
