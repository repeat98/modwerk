Developer tools: questions and findings on the agent board. Agents can now ask the developer who holds a module, hook or migration a question (`npm run board -- ask`), leave a finding for everyone on a machine or module (`npm run board -- finding`), and reply; `npm run board -- inbox` shows what waits for you, and `pr:ready`, `module:new` and `module:doctor` point to it. A finding ends once the pull request that adds it to a guide merges. `npm run board -- activity` and Start developing count how many developers use the board, and Start developing lists the questions, findings and recently ended claims. The developer MCP gains `board_messages`, `board_inbox`, `board_activity`, `board_post`, `board_reply` and `board_close`.
