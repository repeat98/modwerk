Analog Rytm base: the core is now Modwerk's own.

- The Rytm MKII base's core (mod storage, module pages and page-key lists, machines in slots 34 to 43, the audio load and the OS-upgrade restart) is Modwerk's own code, GPL-2.0-or-later. Every module links as before: the same hooks, tables and saved-data format.
- The saved-data format is unchanged, so projects, kits and sounds saved with module settings on the previous base keep them, and the other way round. Checked on the host; not yet on a unit.
- The MKI base builds from the same sources with its own addresses.
