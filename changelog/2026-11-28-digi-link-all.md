SDK: `npm run digi:link-all -- --machine digitakt|digitone [--pairs] [--core FILE] [--stock OS.syx]` links every Digitakt mk1 or Digitone mk1 module in the library, alone and with every other module, against the core a build picks today or a given one, with the frameworks it needs. It reports each set that does not link, so a new core or base can be checked against everything that ships. With the stock OS it also checks each site's stock bytes and whole instructions.
