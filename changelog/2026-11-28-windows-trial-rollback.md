Fix: on Windows, Octatrack `device:test` / soak trials in `octatrack-test.py` and `test-procedure.mjs` now roll back after the trial ends. Windows cannot SIGINT a child the way Unix does, so the trial process was killed without its rollback handler; the scripts now terminate and run `device recover`, matching `device:price`. `trial_command` returns `(command, share)` and the unit tests follow that; macOS/Linux keep the SIGINT path. Checked on Windows 11 with Micro Timing Keep-safe trials.
