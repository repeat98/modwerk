Octatrack base: CPU FULL now refuses exactly the machine and effect picks that would make the unit drop audio, using one figure: how much of each audio frame the unit spends, against 50 %. Before, the CPU meter judged picks. It let SYNTIZ, Analog BD, FM Synth and Tape Echo in past the point where renders drop, and it turned Amiga and POLY8 away when they fit. The site now sends each module's measured cost with the set. Every CPU FULL box looks the same (the module NEEDS +X%, a CPU bar), and the box after an effect pick shows the same figure against the same line.
