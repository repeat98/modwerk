Octatrack base: CPU FULL now refuses the machine and effect picks that would make the unit drop audio, using one figure: the longest audio frame of the last four seconds, against 115 % of a frame. Before, the CPU meter judged picks. It let SYNTIZ, Analog BD, FM Synth and Tape Echo in past the point where renders drop, and it turned Amiga and POLY8 away when they fit. The site now sends each module's measured cost with the set: what the first one on a Part adds, and what each further one adds. Every pick leaves room for a full stock Part, so modules placed on an empty pattern can't later starve its trigs and samples. Every CPU FULL box looks the same (the module NEEDS +X%, a CPU bar), and the box after an effect pick shows the same figure against the same line.
