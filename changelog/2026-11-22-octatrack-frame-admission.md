Octatrack base: CPU FULL now refuses the machine and effect picks that would make the unit drop audio, using one figure: the longest audio frame of the last four seconds, against 120 % of a frame, just under where the unit first dropped audio. Before, the CPU meter judged picks. It let SYNTIZ, Analog BD, FM Synth and Tape Echo in past the point where renders drop, and it turned Amiga and POLY8 away when they fit. The site now sends each module's measured cost with the set: what the first one on a Part adds, and what each further one adds. Every pick leaves room for a full stock Part, so modules placed on an empty pattern can't later starve its trigs and samples. Every CPU FULL box now looks like DSP FULL: what the module needs, a DSP row if it also runs on the DSP, and a CPU bar showing what the unit uses now, with this module's share shaded. On a Part whose own sound leaves no room, it says PART IS BUSY. No module render may now stretch an audio frame past 122 %, because one frame much longer than that can stop the audio until a power cycle. If a pattern or Part change still overloads the unit, module machines go silent until STOP or the next Part change, so stock keeps playing.
