Development: `npm run module:dev -- <id>` builds an Octatrack module from its source and tries it on your unit over USB in one command, undone when the trial ends; `--watch` does it again on every save. It uses the builder the site's packages come from, so a listed effect builds byte for byte as published, and a draft effect gets its page from its own manifest. `npm run module:new` now starts an Octatrack module as a draft in `sdk/drafts/`, named after itself in the FX list, with a short README and TESTING.md. `module:doctor -- --draft` judges a draft on what trying and sharing it needs and lists what listing it needs as still to do; `--release` judges every line. `docs/OCTATRACK_API.md` lists what an Octatrack module builds against: entry points, hooks, state and what stays stable.
