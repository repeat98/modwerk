SDK: the Octatrack has a shared scale, `sdk/machines/octatrack/modwerk_scale.s` with `include/modwerk_scale.h`. It holds octabam's 52-ID catalogue (re-vendored from `modules/scales` with its import record and MIT notice) and one stateless snap (note, scale ID, root; ties go down). The base and card builds compile the same file. A 24-entry table maps Scale Quantizer's saved scales to catalogue IDs, so old projects keep their scale. A host test checks the table against the vendored file and, where ColdFire binutils and Unicorn are installed, runs the snap against Scale Quantizer's for every note, scale and root. No module or base image changes.
