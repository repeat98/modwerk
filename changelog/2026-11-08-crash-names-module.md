Octatrack base: a crash record now names the installed modules behind it. Before the restart, the base looks the crash address and the eight stack words up in its own table of installed modules. At the next start, the crash in the unit's log carries the module at the crash address and the ones it was called through, so shared diagnostics and `npm run diagnostics:pull` say "crash pc … in Mini Verb, stack through …" instead of a bare address. The lookup reads only the base's own table, never module memory, and runs on its own stack. If the lookup itself fails, the unit restarts without the names.
