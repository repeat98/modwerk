Module guides: a module's category now follows where it acts, not the menu that switches it on. An effect processes the audio its FX slot receives, on the DSP; a module that makes or replaces a track's sound is a machine; one that makes or changes notes is a MIDI generator or MIDI effect. The table at the top of [the module guides](../docs/module-guides/README.md#choose-the-category) says when to choose each category, `/modwerk-new-module` settles the category in its plan before any code, and the pull request review checks it. `npm run module:doctor` now refuses an effect whose performance record prices audio work on the ColdFire, because that work makes the track's sound. It flags FRACT (#926), a granulator that replaced its Flex track's source from an FX2 slot, and no listed module. Checked by running the doctor on #926's files and `npm run check`.
