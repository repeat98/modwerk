For developers: the Octatrack's modules moved from sdk/octabam/modules to sdk/octatrack/modules, where every other machine keeps its own. sdk/octabam now holds octabam's tooling only. Run npm run prepare (npm ci does) after pulling: it mirrors the modules to the old path for the tools that still look there, untracked. Edit modules in sdk/octatrack/modules only. An open pull request that touches an Octatrack module needs main merged in; Git follows the move.
