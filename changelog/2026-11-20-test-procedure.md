Development: Every module or base change goes through one test procedure, `npm run test:procedure -- <module id>` or `--base`. It runs the software checks, the build, the emulator and the unit steps in a fixed order, stops at the first failure, records unit steps as not run without a unit, and writes a record with an empty table for the change's own edge cases (docs/TEST_PROCEDURE.md). A ready pull request that changes what runs on an instrument now lists those edge cases, or says "Edge cases: none, because …".
