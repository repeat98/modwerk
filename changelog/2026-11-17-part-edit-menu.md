Improvement: Octatrack base 0.7.9 carries a shared Part Edit menu, the `ot_part_menu` table, so modules that add to FUNC+PART no longer patch its opener and can be installed together. With a module adding a row, FUNC+PART opens a window drawn like the PROJECT menu: PART (stock's RENAME, RELOAD, SAVE and SAVE ALL) and one icon row per module on the left, the highlighted row's actions on the right. UP/DOWN or LEVEL move, RIGHT or YES go in, LEFT goes back, NO closes, and it reopens where it was left, as PROJECT does. With none, the window is stock's. Pattern Sample Locks 0.1.9 is its first row (LOCKS). Checked with the menu's host test (test_part_menu.c), the hook coverage and compatibility checks, and a development base on an MKII with Pattern Sample Locks and Kits rows installed.
