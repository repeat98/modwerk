Octatrack base: modules get twice the room. The memory all modules share grows from 768 KiB to 2 MiB, so a large set installs where the Octatrack refused some of it before, and one module may now hold up to 256 KiB of code and data and 512 KiB with its working memory, enough for the Quadraverb's 48 programs. The room comes from sample memory: Flex machines and recorders have 1.5 MB less of the 85.5 MB, about 9 seconds of 16-bit stereo audio (18 seconds mono). The site checks a set against 2 MiB on this base and against 768 KiB on earlier ones, and the diagnostics log names module memory past 1 MiB while older records read as before. Ships with the next base. It has not run on a unit yet.
