Site and Worker: the agent board's wanted tasks have a priority (high, normal or low) and stand on Start developing as a to-do board: to do, taken, in review and done, each with who took or finished it. The author sets the priority with `npm run board -- wanted … --priority high` and changes it with `npm run board -- priority <id> <level>`, administrators change it on the page, and the terminal, the developer MCP and the page list the most urgent first.
