SDK: a card package may now carry guarded copies of stock data, not only replays of the instructions its detours displace. Each copy must match a guard its module's import record declares under stockGuards (kind guarded-local-cpu-read: address, bytes, SHA-256), so a reviewer sees every span a module reads from the OS; the builder fills them from the user's verified OS at build time, as it already does for replay spans. Packages still carry no stock bytes. The rule moved into scripts/stock-copy-policy.mjs, with tests.
