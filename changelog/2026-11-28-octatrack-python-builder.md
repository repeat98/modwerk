SDK: the Octatrack base and its module packages are built with Modwerk's own Python firmware builder (`sdk/firmware_builder`): the package reader, linker, OS containers and patch step, the SDK's ELF reader and build, and the Octatrack module port. Built code is unchanged byte for byte: the base package differs only in its identity, which follows its build inputs, and every port, candidate package and DSP source matched the previous tools. Reviewed recipes now pin the builder's files instead of the upstream checkout's, and generated glue names `firmware_builder.sdk.octabam`.
