Octatrack base (beta, with the next base): the module status word that the device tool and diagnostics read no longer keeps the value of a module you removed. Once the installed set changes it starts again at 0, so it shows only what a module installed now wrote, and 0 when none of them writes it. Before, a removed module's value stayed until a power cycle when no remaining module wrote the word. This makes the word trustworthy for finding out which module's tick runs; why Pattern Sample Locks' menu rows were missing in the reported trials is not explained by it and is still open.
