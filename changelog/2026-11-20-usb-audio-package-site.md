Sets will install one USB Audio module when the configurable package is published. Choose the layout, stem tap and four Outbox stereo sources under PROJ > MODWERK > SETTINGS > USB AUDIO on the Octatrack. A paired browser leaves a USB Audio trial from another session running when the instrument reconnects. Existing sets retain their USB layout, track tap and Outbox assignments during migration.

During a layout change, the Octatrack can offer the new USB configuration a second time if a powered connection fails to attach.
