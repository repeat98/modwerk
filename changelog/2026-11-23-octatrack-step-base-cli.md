Development: `npm run device -- boot` and `flash` now say when a base is too big for the unit's running base to stage (1.25 MiB on bases before 13 November 2026), instead of "does not match its base, size or private build pin", and point to the step base. `npm run octatrack:base -- --stock OS.bin --step --out DIR` builds the step base's folder from its pinned assets, so a unit on an older base reaches the current one from the command line as the site does: boot and flash the step base, then the new one. Done on an MKII from `1bcbe613` to base 0.8.1.
