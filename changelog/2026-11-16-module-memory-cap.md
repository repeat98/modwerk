Octatrack base 0.7.4: one module may now use up to 288 KiB of the shared module memory (its code still up to 128 KiB), so MIDI Scenes can keep its scene locks for all 64 Parts of a project. The shared memory stays 768 KiB, so no sample memory is lost, and every module that loads today loads as before. The site checks the same limit before it sends a module. A module may also borrow sample memory while it is installed (Kits keeps its library there): the unit's free sample memory shows the 2 MB less only while that module is installed, and gets it back when it is removed.
