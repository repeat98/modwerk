Octatrack base: MISSING MODULES now says which effect slot names a missing effect and how many other places name it too, for example BANK B PART 4 T4 FX1 +2. Before, it named only the track and only the first place, so a missing effect on FX2, or one named in several Parts, took a fix and a project load for each place to find. SAVED in the line still means only that Part's saved copy names it, the one a RELOAD brings back: SAVE the Part to clear it. Ships with the next base.
