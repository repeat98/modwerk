Octatrack base (beta): hold PROJ while you switch the Octatrack on to start it without your modules (MODULES SKIPPED); the next normal start loads them again. On an MKI, which has no PROJ key, press and hold FUNC as soon as the startup animation begins: FUNC held from power-on opens Elektron's Startup Menu instead.
USB Audio is now off in the base by default (USB MIDI only). If your module set has the USB Audio module, a base install or update puts your set's layout on in one go. Without it, the update turns USB Audio off, and the update window says so before it starts: if you stream audio over USB on the previous base, add the USB Audio module to your set before you update.
