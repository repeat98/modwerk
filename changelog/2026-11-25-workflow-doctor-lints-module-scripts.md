Development: `npm run module:doctor` runs `npm run lint`'s rules on an Octatrack module's own scripts (`.js`, `.mjs`, `.ts`) and shows a red `lint` line among a draft's experimental lines. Before, a lint error in a module's helper script showed up only at `pr:ready`, after the evidence was stamped on that source, and fixing it then moved the source hashes and needed the packages rebuilt.
