SDK (Octatrack card builds): the card-build counterpart of the base's `ev_trig_muted` (#777). A card build has no base, so a machine that starts its own note from a trig could not learn which trigs a mute module drops. `sdk/machines/octatrack/card/trig_muted.inc` names one meeting point, `modwerk_card_ev_trig_muted`: a mute module answers it from a DRAM unit, a machine asks it from a DRAM unit, and with either one missing nothing changes in what plays (the ask is 0). Bits 0-7 are `ev_trig_muted`'s answer; bits 8-15 name the tracks whose sounding note the mute ends (OTFX-T). No module answers or asks it yet. Checked by host tests: the native DRAM link and the configurator's linker give the same bytes for every combination and refuse a second answer.
