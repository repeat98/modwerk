Analog Rytm MKII: the builder takes core-ar2 0.7, irpina's new pre-release, for OS 1.74. Its parameter pages let several modules add pages behind the same stock page key, and it adds mod machines, page functions, write-through of a module's page settings and a safe OS-upgrade restart. Filter Hz, Loop Sync and Retrig Grid build with it as before. The SDK guide and the core profile describe the new tables, and the SDK carries elekloader's pages.h, machines.h and load.h. rytm2_mods v1.2's own-page mods (euclid-accents, velocity-humanise among Modwerk's submissions) do not link with 0.7; their 0.4 versions do.
