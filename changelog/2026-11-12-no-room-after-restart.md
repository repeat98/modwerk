Octatrack base: after a restart, effect picks could all be refused with NO ROOM when Sidechain was installed and a module effect with a full delay buffer (Air Chorus, for one) sat on T1 or T5 FX2. The effect had taken memory that Sidechain's key bus needs before Sidechain was ready. An installed Sidechain now keeps that memory free from the start. When an effect that needs no delay memory is refused, the box now says that another module effect is in the way and to remove and re-add it, instead of blaming the tracks of the effect picked.
