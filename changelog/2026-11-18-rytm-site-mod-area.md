Analog Rytm MKII: a module set no longer has to fit 128 KiB. The site now builds every Rytm set on base 0.7.1, which gives the modules 3.7 MiB of the same memory, so memory no longer limits how many modules a set holds (the storage they share and their conflicts still do), and a module can hold larger buffers. A firmware you built before keeps its layout; the next one you build uses the new one. That memory was read as unused in stock OS 1.74 and held a test pattern on one unit while it played, loaded, streamed Overbridge and saved, and sets placed there ran (development builds booted from RAM, 17 November 2026). Not tested yet: base 0.7.1 itself on a unit, a flashed set in the new place, an OS upgrade, a +Drive format, a power-off save and a second unit. For developers: `scripts/link-image.mjs` gives a 0.7.1 base the same area, and its send effects' work area now ends at `0x47F00000`.
