Digitakt and Digitone builds take elekloader's newer cores: core 4.4 on Digitakt OS 1.53 and 1.54, core 5.4 on Digitone OS 1.43 and 1.44. Mods made for them can come to the library next. A set the new core does not combine with builds on the core it used before, byte for byte the same: Digi EQ on the Digitakt and KitBank on Digitone 1.44. CC Names now builds beside DIGISLICER, since core 4 leaves mods 256 KB.
