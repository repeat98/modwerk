Octatrack base (beta): switching a track between FLEX and a module machine (Analog BD, FM Synth and the others that run on a FLEX track) now reloads the track's live parameters from its Part, as stock does when a switch changes the machine type. Before, the switch left them on the old machine's values until SOURCE CLEAR: a machine chosen from FLEX could stay silent, and FLEX chosen back played the machine's settings. STATIC and the other stock machines are unchanged. Checked in the host test and on a MKII (development base: the live parameters before and after each switch, and by ear).
