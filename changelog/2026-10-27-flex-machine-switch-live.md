Octatrack base (beta): switching a track from FLEX to Analog BD or FM Synth, or from any module machine back to FLEX, now reloads the track's live parameters from its Part, as stock does when a switch changes the machine type. Before, the switch left them on the old machine's values until SOURCE CLEAR: a machine chosen from FLEX could stay silent, and FLEX chosen back played the machine's settings. STATIC and the other stock machines are unchanged. Checked in the host test and on a MKII for Analog BD (development base: the live parameters before and after each switch, and by ear); FM Synth, POLY8 and VECTOR not yet tried on a unit.
