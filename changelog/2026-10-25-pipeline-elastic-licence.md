Licensing: the GitHub workflows (module checks, author releases, pull request triage, site and Worker deployment) and the owner's own build, release, device and service tools now carry the Elastic License 2.0 like the backend, so they can't be offered to others as a hosted service without permission. 23 files are listed as `pipelineFiles` in `LICENSES/platform.json`, each with an `Elastic-2.0` header, after an audit found only the owner's and the owner's coding assistants' work in them. `npm run licenses:check` now also refuses GPL code that imports such a file or loads it in-process, and a pipeline file that reaches GPL code. Most of the submission checks, the in-browser builder, the USB link, the developer MCP and the firmware download stay GPL: they link Elekloader's GPL kit or contain outside contributions ([platform licensing](docs/PLATFORM_LICENSING.md#pipeline-files-25-october-2026)). Earlier revisions remain available under the GPL.
