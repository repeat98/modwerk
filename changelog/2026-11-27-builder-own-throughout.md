Firmware builder: the site now builds every machine's firmware with Modwerk's own builder end to end (`src/engine/elektron/builder.ts`): the worker, the catalog, the build steps, the package model and the manifest, besides the pieces before. The vendored kit's code is gone; only the upstream checkout pin and one re-export stay for the Octatrack base's build tools. Builds are unchanged: whole builds on the stock Digitakt 1.53/1.54, Digitakt II 1.17 and Digitone 1.43/1.44 files gave the same firmware, symbol map and manifest as before (34 builds, 26 refusals), the manifest now naming `"patcher": "modwerk"`. The build page credits Modwerk's builder, and `npm run elekloader:update` downloads and verifies catalog packages itself.
