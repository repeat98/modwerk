SDK: Modwerk's own Digitakt mk1 base, version 5.0 for OS 1.53 and 1.54 (`sdk/machines/digitakt/base`). It boots the mods, runs their hooks, lists the SRC machines they add and draws the SRC and LFO pages of machines that describe their own, so the machine mods need no separate dependency; a code-free `machine-pages` 2.0 package keeps them building unchanged. Every shipped Digitakt mod links on it alone and in pairs on both OSes. `npm run elemod:base -- digitakt` builds it from source; `digi:link-all` takes `--package` for its companion. It has not run on a unit yet, so site builds are unchanged. In the shared core, `core_additem` now hands only the select and change callbacks the menu as their payload.
