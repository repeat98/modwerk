SDK tooling: the Octatrack builders and checks run the pinned Elekloader checkout with Modwerk's own firmware codec, `sdk/firmware_codec`: the section format of OS images, the `.syx` transport and ColdFire instruction lengths, for every machine. Scripts put the checkout on `sys.path` only through `firmware_codec.use_elekloader()`, which serves the codec in place of the checkout's `codec/` and `isa/`, and `sdk/tests/test_firmware_codec.py` fails on a script that reaches the checkout any other way. The reviewed recipes that pin a build's inputs (CC Map, Mute Modes, Tape Echo, Euclid and the machine packages) name the codec's files now; Tape Echo's and Euclid's also take the page builder files they had fallen behind, so `npm run octatrack:module-packages -- --check` runs through again. Rebuilt with the new tooling, all 27 published USB packages are byte-identical (Play Modes stays held at 0.1.1, #764), and the beta base built from unchanged sources with the new codec is byte for byte the committed one (`903f8ed6`, all seven USB Audio variants).
