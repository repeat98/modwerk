SDK tooling: the browser builders and the Node tooling now pack and unpack firmware sections, write the SysEx transport and classify ColdFire instructions with Modwerk's own codec in `src/engine/elektron/codec/`. The vendored elekloader kit's four matching files re-export it ([replaced kit files](vendor/elekloader/README.md#replaced-kit-files)), and `npm run elekloader:check` and `elekloader:update` keep it that way across kit updates. Every output is byte-identical to before: `codec.test.ts` checks recorded digests of packed sections in both modes, depack refusals, the transport and all 65,536 ColdFire opwords in both decoder variants, and locally the Octatrack OS 1.40C main image packs to the same bytes. No build, base or package changes.
