Octatrack over USB: when the Octatrack turns a module down because the code under one of its sites is not what the module expects, the site now says so and that nothing changed, instead of the plain “can’t run this module file”. The loader's refusals now live in one list (`sdk/runtime/loader-refusals.json`) that the site and `npm run device` read, and a test holds it, and the diagnostics' own copy, to the loader's codes; the device tool names a refusal and the next step instead of printing its number.

Octatrack SDK: `npm run coldfire:isa` assembles every hand-written ColdFire source for the unit's MCF54455 and names each instruction that CPU lacks (an FPU form, a word or scale-eight index), which until now was checked only for C code. Today's sources pass, and `sdk:check` keeps them there.
