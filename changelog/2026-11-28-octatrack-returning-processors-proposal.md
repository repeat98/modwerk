Proposed Octatrack Base support lets modules process a track before FX1 and FX2
while leaving both slots available. Several processors can share the route;
their code and updates remain in their own packages. This is a draft shared
service, not a released M/S module. Exact-build hardware qualification is pending.
Bindings describe the compiled DSP services, so the library follows the published Base.
The stock-free Linux rebuild reproduces all authored package bytes; provenance and the scan table are regenerated.
