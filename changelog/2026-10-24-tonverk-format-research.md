Tonverk format research: the OS 1.4.1 update container is documented stock-free in docs/TONVERK_OS_RESEARCH.md. It is a SWUpdate .swu — a cpio archive whose manifest and payloads are encrypted with device-held keys behind an RSA-3072 signature chain — so the stock file can be repacked exactly but not modified and re-signed, and the machine's mod route needs an owner-level platform decision. The Tonverk profile moves to research status with the format step started, and Add a machine gains a section on researching Linux-class OS images.
