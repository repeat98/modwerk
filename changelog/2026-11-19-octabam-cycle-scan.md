SDK: octabam's cycle scan is imported at `cc7cffc1` into `sdk/cycle-scan/`. It prices the path an Octatrack DSP effect executes with the DSP56300 manual's instruction cycles and pipeline stalls and names the sites that stall. `node scripts/cycle-scan.mjs record` commits a module's scan, and `npm run check` fails one whose source changed since or whose performance.json records far fewer instructions than the scan saw executing. It sits outside the module-source fingerprint, so no module package needs a rebuild.
