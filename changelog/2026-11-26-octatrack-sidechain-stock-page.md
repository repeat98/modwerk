Octatrack base 0.8.2: Sidechain Compressor no longer stays the stock COMPRESSOR (no KEY page) when E-Verb, Resonator or other big effects run on the same DSP core. Big effects now load below the memory Sidechain needs, so picking COMPRESSOR brings up its KEY page straight away. When a Part really leaves no room, the unit shows SIDECHAIN PAUSED / DSP MEMORY instead of silently showing the stock page.
