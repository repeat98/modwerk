SDK: a module trial on the Octatrack now ends with a verdict. `npm run device -- try` (and so `module:dev`) reads the unit's log before and after the trial; a crash, DSP stall, frozen UI or skipped track during it fails the trial and rolls it back even with `--accept`. A module's own `test_*.py` host tests now run: `module:doctor` runs the module's, and `sdk:check` runs every listed module's on each pull request. The `module:new` templates point at Modwerk's commands and folders, and a test keeps a fresh draft of each kind passing the draft doctor and building.
