Development: `/modwerk-contribute` and `/modwerk-fix-issue` now look for merged pull requests as well as open ones before they offer or start a fix. An issue stays open after its fix merges, until the owner has checked the live site, so a contributor's agent could offer an issue someone had already fixed and only find out when merging `main` before opening its pull request. `/modwerk-contribute` also checks the pick again before it starts and stops before opening a pull request when `main` already has the change.
