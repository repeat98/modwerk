Analog Four MKII: Modwerk's linker and module tools know the Analog Four MKII on OS 1.56. The linker reads its OS file and links core-a4 0.2 with A4 mods to the same main OS image and mod storage lockfile as elekloader, checked on the stock 1.56 file with core alone, each of elekloader's five A4 examples and three of them together. The module scripts (change scope, module doctor, author updates, release and source-parity checks) take modules from sdk/analog-four-mkii/modules. The browser does not build A4 firmware yet.
