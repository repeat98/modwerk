Octatrack base 0.7.3: machines are in the project's module map. A project now remembers which machine each track uses (POLY8, VECTOR, FM Synth and the rest), so when one is switched off or not installed, PROJECT > MODWERK > MISSING names it with where it is used, YES switches it back on if it is switched off, and selecting its track says POLY8 IS OFF or MISSING POLY8. Before, such a track just played as FLEX without a word. The site's missing list shows these machines too.
