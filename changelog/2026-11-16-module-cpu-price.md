SDK: every Octatrack module names its CPU price in its manifest (`resources.cpuPrice`): the value in percent of a frame, what was measured, the tool, the day and the conditions. A machine names its worst render (`npm run device -- cpu`), and its descriptor's `reserved[0]`, the figure the base admits machines by, must carry the same number; any other module names the frame interrupt's share (`npm run device:price`). `npm run modules:check`, so CI and `pr:ready`, and `module:doctor` refuse a module without one and say how to measure it. The modules listed before 17 November 2026 wait on `sdk/module-cpu-prices-pending.json` until they are measured on a unit; that list only shrinks.
