Pull requests: a draft module update no longer fails every check while its hardware evidence is still to come. From 20 to 21 November, 30 of 45 failed PR runs were drafts of POLY8, Tape Echo, EUCLID, Repitch, Quantizer and Grain waiting for their unit test: the missing qualification, captures or owner approval stopped catalogue generation, and the stale catalogue then failed the changelog check, the suites, the Windows paths and `octatrack-source` too. In a draft PR, `modules:check` and `modules:generate` now list that missing evidence as warnings and the other checks run; `npm run pr:ready -- --draft` does the same locally. Marking the PR ready reruns every check without the exception, and `main` never has it. Checked with a draft case in `src/catalog/module-publication.test.ts` (the missing screenshots warn, missing resource estimates still fail) and `npm run pr:ready`.
