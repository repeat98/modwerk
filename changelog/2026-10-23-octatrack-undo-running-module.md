Octatrack base (beta): Undo no longer leaves the Octatrack stuck until a power cycle when the set added a module your project already uses on a track. The same happened when a failed self-test undid such a set by itself; the next sync then said the Octatrack was busy (beta finding 66). The base now puts those tracks back to dry, as they were before the sync, and removes the module. A track that only regains its effect on a trig shows NONE rather than MISSING until its Part is applied again, which sounds the same. New beta base `cd39c494`.
