Octatrack base (beta): Ringmod SC, and any module that reads the key bus, now syncs whatever the Part on screen runs. Before, the base refused it with "This module needs more DSP time than an effect slot has." whenever that Part's effects or an Analog BD voice left a DSP core without room for the key bus tap (72 cycles a core). The tap is only charged once a Part uses the module, and the Part can change at any time, so that check promised nothing. The tap's price is now paid when a track picks the module's effect or a Part that uses it loads. If it doesn't fit, the Octatrack shows DSP FULL as for any other effect. The box counts the tap in what the pick adds and shows the DSP core that ran out: the tap runs on both cores, so that can be T5-8 when the effect was picked on T1-4. New beta base `56c44acc`; Analog BD, Output Matrix and Sidechain are relinked to it with their code unchanged. Limits: checked in host tests and a source build only; not yet run on a unit.

Octatrack over USB (beta): when a base update over USB loses the connection, the dialog says "The Octatrack stopped answering." instead of the link's internal message ("hello was not confirmed; no further commands will be sent on this connection.").
