Octatrack card builds: no module code goes into the stock DELAY's filter table any more. The 2 KB after DELAY's curve, which earlier card builds used as spare room, is read by DELAY as filter coefficients at ordinary settings, so code there could make its repeats darker or thinner (found in an emulator, not heard on a unit). Card builds no longer place overflow code there, and a selection that needed that room is refused instead.

Developers: `npm run modules:compat` and both card builders refuse a cave, unit or patch in 0x400d24d0..0x400d2ca7; Scale Quantizer's two pinned units after it, and MIDI Scenes' scene-mute patches over the bytes its author image already places there, are the only exceptions. FM Synth 0.1.2 pins its SRC page there; FM Synth 0.1.4 moves it into DRAM.
