Octatrack base (beta): a sync that adds Ringmod SC (or any key-bus reader) no longer hangs in "publishing". When the same set also removed Sidechain and added an effect the project already uses, that effect started running before Ringmod SC's turn and took the DSP time the key bus's tap needed. The base refused Ringmod SC at every retry, the site gave up with "The Octatrack stopped answering", and undo was refused until a power cycle (beta finding 64). The tap's price is now checked when a package is admitted. Later in the same set the reader goes in, and its key bus waits for room, as an engine does. New beta base `70d445f4` (with the MISSING MODULES change below); Analog BD, Output Matrix and Sidechain are relinked to it with their code unchanged. Still open: a set whose rows are refused for another reason can still stall, and undo still can't remove a module a track is already running.

Octatrack base (beta): MISSING MODULES says where each module is used, for example "BANK A PART 1 T2", or "BANK C SAVED PART 2 T5" when only a Part's saved copy names it. The list counts every bank, working and saved Parts alike, and the track's FX page showed NONE in that slot, so testers took it for modules they don't use. A missing module's slot now reads MISSING (MISS in the footer). It still runs dry as before.
