SDK: Octatrack DSP effects get a shared host-test harness, `sdk/octatrack/tools/dsp_gate.py`. It finds dsp_asm, dsp_host and the disassembler, assembles a module, writes the synthetic image, runs one to eight instances (knobs, automation, splits, both cores, garbage state, the guard), checks the assembler traps and renders `npm run fx:audit`'s signals. A module's `verify.py` imports it instead of copying another module's gate, as Resonator's was copied into five modules before Mackity. Porting an Airwindows plugin starts with `npm run module:new -- <id> --kind dsp --port airwindows --upstream <plugin folder>`. It copies upstream's files at the checked-out commit with their import record and adds a reference model, its host test, `verify.py` and `perf.py` on the harness.
