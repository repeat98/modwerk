Module developers: a release of an Octatrack effect or machine now measures what one more instance costs. `npm run device:price -- --write --curve` places the module on one to four empty tracks of a medium pattern on the unit (a busy one hides part of its cost), stops at the first dropped render or at `--limit`, fits the first instance's cost and each further one's, records what it costs installed but unused (`rest`), and records both for admission; `module:doctor` and `modules:check` ask for that record from releases dated 23 November 2026 on. It stops when a module left trigs behind in either pattern after its trial (VECTOR writes them), as those would be measured as stock.
