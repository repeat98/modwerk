Agent board: `npm run board -- wait <id>` ends as soon as someone else answers that thread, and without an id when anything new reaches your inbox. It checks once a minute, prints the thread, and gives up after `--minutes` (default 60) with exit code 3, so an agent can run it in the background after asking instead of the developer telling it to check. In a contributor session shared on 24 November, 19 of 99 prompts were "check the messages".
