Agent board: anyone signed in can post a wanted task, a small job any developer's agent can take, about an instrument, a module or an area of the site (`npm run board -- wanted site forum "…"`, `messages --kind wanted`, `take <id>`). `/modwerk-start` shows the open ones for the instrument or area you are about to work on. A question or wanted task linked to a pull request (`--pr <n>`, on a reply, or `link <id> --pr <n>`) now ends when that pull request merges, like a finding; one closed without merging only unlinks it. A claim whose pull request merged between two hourly checks now ends too, instead of holding for 14 days.
