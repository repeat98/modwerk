Site: once Modwerk hosts the Octatrack base, its install guide offers the prebuilt base to verified members, so it installs without your own OS 1.40C file; you can still choose your own. The guide's anonymous step counts tell the two apart (`hosted-base-ready`, `hosted-download-failed`). The owner builds and uploads the images with `npm run base:publish`, using the same build path as the browser, and the Worker serves them at `/api/bases`. The modding guidelines and agent rules now name this one exception to sharing no firmware: hosted base images, for makers who agreed.
