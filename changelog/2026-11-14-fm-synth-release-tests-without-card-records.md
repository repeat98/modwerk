Checks: FM Synth's two release tests no longer ask for records that only the removed card composer could make (a regression run on a composed card image, captures bound to a native card image, the native comparison). Those tools left the repository on 12 November 2026, so no new FM Synth version could pass. The tests keep what can still be checked: the source and licence pins, the owner's approval of the exact source, the screenshots' hashes, and that an update either has captures of its own version or names the version it keeps them from.
