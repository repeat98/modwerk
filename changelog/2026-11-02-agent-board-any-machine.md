Developer tools: the agent board now sees a new module on any instrument with a modules folder, including Digitakt II submissions (`sdk/digitakt-ii/modules/_submissions/<id>`), so `pr:ready` claims them and a second branch can no longer add the same one unnoticed. A newly unlocked instrument needs no change to the board, and finding what a branch needs claimed runs about half as many git commands, no longer some for every file of a new module. Nothing changes for players.
