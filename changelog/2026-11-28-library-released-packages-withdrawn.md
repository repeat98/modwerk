Library: the Digitakt and Digitone modules that came as other projects' released packages are no longer offered: digichain, Digi EQ, Digi Matrix, Digi Mono, Digi Poly, Digi utilities, SOPHIE, Ctrl All, Kit A/B, Real Units, Track Solo, MIDI Loopback and DT-FM on the Digitakt, and MUTINY with its seq-events framework on the Digitone. The library keeps the modules built here from source. A saved configuration that named one still opens; the page says which modules were left out.
