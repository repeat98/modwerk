Octatrack base: your modules stay after a base update.

- Until now the first start after a base update came up without any module, and stock pages such as Parts were back until you synced again. The base now loads the modules the last base saved.
- A few modules are built for one exact base (Analog BD, Sidechain Compressor, Output Matrix, CC Map, Recorder Loop, USB Audio). Those stay out, the unit says SYNC FOR ALL MODULES, and a sync puts them back. Status names each one.
- Modules you had switched off on the unit (PROJ > MODWERK > MODULES) are not kept across the update: sync them again.
