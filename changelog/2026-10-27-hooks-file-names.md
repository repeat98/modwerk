Development: the Octatrack's hook files carry the new name. The registry is `sdk/machines/octatrack/hooks.json`, its generator `hooks.py`, the header modules include `include/modwerk_hooks.h`, and the base's generated dispatch `elekloader/runtime_hooks.s` and `.h`. A module's `runtime.json` names the hook it subscribes to with `"hook"`; `"event"` is still read, so existing modules need no change. This changes the base's sources, so it ships with a new base build.
