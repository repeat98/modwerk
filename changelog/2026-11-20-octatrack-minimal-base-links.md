Octatrack base 0.7.11, for developers: a base built without the resident stock hooks (a minimal development base, such as one with only site events and table owners) links again. Its machine registry counted every machine assignment into a variable that only the controller board defined, so the core link stopped on an unresolved import; the registry now defines it when no controller board is linked. The beta base's code is unchanged; only its identity moves with the source.
