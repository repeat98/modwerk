Octatrack base (USB, beta): installed modules take less of the Octatrack's CPU. Many times a second, the base checked every installed module once for each Sidechain, Output Matrix or Analog BD it held, reading each module's header from slow memory every time. With 26 modules installed and those three among them, that took 0.8 ms of every UI tick (about 5 % of the CPU) even when no track used them. The base now reads only the one module it is looking for and remembers the answer until the installed set changes, checking that module's header again each time. With the same 26 modules, the base's own work per UI tick fell from 1.0 ms to 0.4 ms, about 4 % of the CPU returned; with a few modules the saving is smaller. New beta base `109f23bd`; Analog BD, Output Matrix, Recorder Loop Fix and Sidechain are relinked to it with their code unchanged. Limits: FM Synth, POLY8 and Euclid still cost 1-2 points each in the frame interrupt while installed, even unused; that is their own code. Measured on development builds of this base on the owner's MKII; the release image was checked with eight modules, not all 26.
