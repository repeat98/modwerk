Development: `npm run pr:ready` refuses a module pull request that also edits `scripts/octatrack-qualify.py`, matching other shared qualification gates, so a chooser-read fix does not ride inside a module release. On `release/<module>` branches it adds catalog and gate-scope reminders; when the push remote is a fork it says which remote must move for the upstream PR to see your commits. A failed check message now suggests `npm run check -- --base <remote>/<branch> --rerun-failed`. `npm run check` warns on piped stdout (tail may own the exit code) and, after a full pass of at least two minutes, suggests `--rerun-failed` for the next iteration. `docs/DEVELOPER_WORKFLOW.md` documents the fork push pattern.
