SDK: the Octatrack core's boot copier, hook bus and gate are now part of the base's own sources (`sdk/machines/octatrack/elekloader/core-ot/`), so building the base, its packages and the other machines' bases needs no upstream checkout: `npm run upstream:tools` no longer fetches one, and the build tools no longer check for it. The base's code is unchanged byte for byte (0.8.4 is now `35af17c2`, only its identity differing).
