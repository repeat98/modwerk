SDK: the Octatrack base boots through Modwerk's own core (`sdk/machines/octatrack/elekloader/core/`): a new boot copier, hook bus and draw gate written from a specification of their interface, on the same stock sites. The base build turns on its parts with build switches instead of editing the core's text, and a change to the core's files now marks the committed base as stale. Not yet tested on a unit.
