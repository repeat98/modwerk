Development: `npm run zoom -- status | list | backup | install | remove` drives a Zoom MultiStomp from Node through the site's own `ZoomLink`, over the computer's MIDI, and the developer MCP has the same operations as `zoom_status`, `zoom_list`, `zoom_backup`, `zoom_install` and `zoom_remove` (started with `--zoom-midi`; installing and removing also need `--allow-device-writes` and `confirm=true`).
