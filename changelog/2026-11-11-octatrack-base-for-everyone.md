Octatrack: the Modwerk base and loading modules over USB are open to everyone, not only beta testers. Whoever has never had the base is welcomed once, on every machine's pages (whoever has no Octatrack closes it for good), with what is new and the three steps: install the base once (the first install goes through the card, because the original OS has no USB link for Modwerk), connect over USB, pick modules and sync. Set up my Octatrack opens the guided install on Your Octatrack, and later base updates go over USB. Card firmware without the base stays as the labelled fallback in Setup, for browsers without USB and for modules with no USB version yet; in a browser without WebUSB the welcome leads there, and modules that need the base are marked USB only and can't be added, with a pointer to Chrome or Edge on a computer. Saved configurations show as module sets. A module set holds at most 20 modules for now: a longer one still opens, but can't be synced or built until it is trimmed, and "Start from what's on it" and "Add to set" no longer stop part way at 20 (paused modules stay out of the set, as before). An Octatrack that held more than 20 before a base update asks you to choose which to put back.

Diagnostics are a free choice for everyone, beta testers included, and nothing depends on them; signing in is optional too (it lets you report problems and share diagnostics, and the site remembers that your Octatrack has the base; module sets stay in this browser). The install guide's last step offers them, and a member who doesn't share is asked once more after a failed sync, self-test or base update, when the Octatrack's audio stops or when it started its previous base (Not now pauses that for 30 days). Under consent version 2026-11-11.1 reports also name the browser and system family and, when connecting fails before a link exists, one of a few fixed reasons (no WebUSB, no Octatrack chosen, access denied, couldn't be opened, in use by another app). Newly counted each day, without any identifier: the install guide's steps, with one fixed reason for a failure (a guide that opens by itself counts once per browser and base), and the answers to the diagnostics invitation by where it was shown. Beta now means beta modules and beta pages: only their bugs go to #beta-testers on Discord, and problems with the base, a sync or a released module go through the site's report forms.

Known limits: Tuner, Stem Rec and Temp Save are card firmware only for now. Over USB, Play Modes installs 0.1.1 (card 0.2.0), VECTOR 0.2.5 (card 0.3.1) and POLY8 0.3.1 (card 0.3.2). Not every module's current version has been run over USB on a unit yet.
