Digitone II: Modwerk's own linker now knows OS 1.12. It links core-dn2 0.3 and 0.4, alone and with elekloader's examples, to exactly the main OS elekloader builds, and takes the core's DSP bridge while refusing mods that bring DSP code, which it cannot write yet. Modwerk's builder now also carries the Digitone II for the site's builder and `npm run machine:base`, which the pinned Elekloader kit does not know. The site builds no Digitone II firmware yet: that waits for the machine's base.
