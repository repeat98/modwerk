Octatrack trials: `device:test` now runs with the CF card left in and proves it left the card alone. In the Grain #1858 release on 21 November, the owner pulled or reinserted the card and power-cycled the unit 10 times, because each trial ran card-free to protect the owner's set. Nothing requires that: a development twin loads no set another base wrote (it reads card set 4, FOREIGN), and a trial writes none. `device:test` now reads the card set (`do saved`) before the install and after the rollback, and fails if they differ. The driving rules and the test-on-unit skill say to leave the card in and to return to the flashed base with `npm run device -- boot <flashed image>`, which loads the owner's set again without a power cycle. Checked with `sdk/tests/test_octatrack_test.py`: an unchanged set passes, a set that reads saved afterwards fails. Not yet run on a unit.
