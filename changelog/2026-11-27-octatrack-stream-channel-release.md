Octatrack base 0.8.4: the stream channel, which moves an effect's long delay lines between the Octatrack's main memory and its DSP every audio frame, is now part of the base, not only of development builds, and runs beside USB audio input. So the Quadraverb plays on the released base. In each frame the base sends USB audio input's block first, as before, then the effect's, then any effect upload, one after another. With no such effect on a track, USB audio input works exactly as it did. One streaming effect plays at a time; a second is refused with STREAM FULL. It has been checked in host tests only; the unit run with the Quadraverb and USB input together is next.
