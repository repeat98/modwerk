Octatrack install and sync: in Safari, Firefox or any other browser without USB, the base install guide now says first that USB needs Chrome, Edge or another Chromium browser on a computer, and leads through the card instead: install the base from the card, then load your modules as one file on the card, with no failure shown. The last card step tells you what to check when your Octatrack isn't in the browser's list. When Modwerk was updated while the page was open, Reload page now brings the guide back where you were. Before a sync that removes or updates modules, the sync dialog says to take them off your tracks first, since the Octatrack refuses to change a module a track is using, and after a failed sync Try again takes you back to the review without closing. The anonymous daily totals now also count each guide step reached and a failed sync's reason from a fixed list, so we can see where installs stop; the privacy page names both.
