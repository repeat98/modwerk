Analog Four MKII: the machine moves to research status with its first four steps done on OS 1.56. The stock file is understood and rebuilt byte for byte, modified OSes boot on a unit and the stock file recovers it over MIDI DIN, and elekloader's core-a4 (the Analog Rytm MKII's core at the A4's addresses, with mod storage and parameter pages) runs on a unit. The profile lists OS 1.56's stock file and hash, how to flash and recover, and the public research behind each step. The machine also gets an elemod SDK: a guide with the core's events, parameter pages, mod storage, budgets and build steps, core-a4 0.2's interface, its two headers and an empty module folder. No module yet, so Modwerk's linker has no Analog Four profile and the browser builds nothing for it.
