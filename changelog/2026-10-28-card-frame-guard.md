Fix: Octatrack card builds: too many module voices no longer stall the Octatrack until a power cycle. The USB beta base has had this guard since #874; card builds now get the same one through the built-in logger that every card build carries. POLY8, FM Synth and VECTOR render in the frame interrupt, and in a busy project that could take the whole frame: the audio stopped and the sequencer would not play again until a power cycle (#844, #1015, likely #981). The frame interrupt now gets 80 % of each frame. A module machine track whose render would go past that plays silence for that moment instead: a dropout on that track while the Octatrack keeps running. Stock tracks and Analog BD always play. OCTAMOD.LOG records the dropouts as `GRD` (how many, which tracks). Existing card files need to be built again to get it. Limits: checked in tests and the emulator only, not yet on a unit; the guard cuts the first module track in the frame, not the most expensive one.
