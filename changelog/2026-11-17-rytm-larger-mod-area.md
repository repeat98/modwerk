Analog Rytm MKII, for developers: an image you link yourself with `scripts/link-image.mjs` may now hold a module set that does not fit the 128 KiB the modules share. Such a set is placed in a larger area of the same memory: 704 KiB, or 3.7 MiB without the send-bus base. A set that fits 128 KiB is built exactly as before, and the site's builder still has the 128 KiB alone. That memory was read as unused in stock OS 1.74 and held a test pattern on one unit through playing, loading, Overbridge, SysEx dumps, an OS upload that was cancelled, a project save and Transfer. Development bases keep the RAM boot's diagnostics outside the modules' memory, where a full set can no longer overwrite them.
