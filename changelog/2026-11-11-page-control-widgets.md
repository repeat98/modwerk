Octatrack SDK: a machine page's control now gets stock's own widget for its number of values from one shared helper, `modwerk_page_control()` in `modwerk_page.h`: a switch for two values, the three-, four- or five-position switch for short lists, a knob for longer ranges. The machines guide names the rule and `module:doctor` refuses a new module that writes a page descriptor by hand, so a short list no longer ends up as a knob.
