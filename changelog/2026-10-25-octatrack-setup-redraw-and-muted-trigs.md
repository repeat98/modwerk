Octatrack base (USB, beta): a module's page on a stock effect now shows as soon as you pick the effect. Since effects load at the pick, Sidechain Compressor's KEY, KFLT, KGN and MON knobs on COMPRESSOR's FX SETUP page stayed hidden behind the stock page (RMS only) until you turned a knob or left and opened SETUP again (#882, likely #868). The base now redraws the screen, and an open FX1 or FX2 SETUP page, whenever a module's page goes on or comes off. The base also answers a new question for machine modules, "is this track's trig muted?" (`ev_trig_muted`, base event index 35): once FM Synth asks it and Mute Modes answers it, FM Synth stops playing muted trigs in Mute Modes' OTFX-T and DT-T modes (#777). With this base alone nothing changes there yet. New beta base `c1ae2ee9`; Analog BD, Output Matrix and Sidechain Compressor are relinked to it with their code unchanged. Limits: checked in host tests and a source build only; not yet run on the emulator or a unit.
