Octatrack: a base update over USB no longer leaves the Octatrack hanging at the logo or frozen while it saves. On an Octatrack with two base slots, the running base used to save the new one itself under the stock upgrade routine, and the base's own DSP watchdog mistook that pause for a crash. Now the new base always starts first and saves itself, the same as on an Octatrack with one copy, and the watchdog stays out of a save. When a save goes unconfirmed, the site no longer warns about the startup menu's MIDI recovery on an Octatrack with two slots, where it never applies.
