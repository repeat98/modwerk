Improvement: an Octatrack package or base is no longer refused for sharing a run of bytes with the stock OS. A module's own code that happens to call the OS the way the OS calls itself (pushing the same arguments, then the same routine) built byte for byte like stock's and was turned away, as Tuner, Temp Save and Amiga were. The package builder, the base build and the private preparation tools now publish such code as it is; the scanner stays as a tool that lists runs, which the capture step still turns into copies from the user's own OS. Checked with the runtime-span and package tests; it ships with Octatrack base 0.7.5.
