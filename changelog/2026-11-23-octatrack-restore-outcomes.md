Octatrack base 0.8: when the Octatrack starts without some of its saved modules, the Status page now names every module it left out and why, instead of only SOME MODULES FAILED: for example that it needed more module memory, or that the last start crashed while loading it. A unit on an older base shows the message it showed before.

Shared diagnostics include which catalogue modules a start left out and the Octatrack's reason codes, never a module's name.
