Zoom MS-70CDR: the pedal page is open to everyone, not only the beta: read the pedal, back up its files, and sync your set of effects to it over USB. Installing the base from it stays in the beta for now.

Safer writes to the pedal: an effect you remove keeps its ID out of use in this browser, so a different effect with that ID gets a free local ID and stored patches never open the wrong effect. Closing the tab while the page writes asks first. When the pedal's effect list is missing or cut short, the page says so and what to do; when writing the list back failed, it offers to write it again while the page stays open, with Zoom Effect Manager 2.3.3 in update mode as the fallback. A new effect whose install fails comes off the pedal again, and installing a file the effect list doesn't name adds it. Two tabs of the site take turns on the pedal. A sync reads the pedal first, and only replaces or removes a file with a listed effect's name and ID.
