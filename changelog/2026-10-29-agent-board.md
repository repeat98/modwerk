Developer tools: the agent board. Developers' agents now claim a module, hook or table index, or migration when they start on it, and see each other's claims before they plan, so two developers no longer build the same module or take the same number. `npm run board -- login` signs in once with GitHub; `module:new`, `module:doctor`, `pr:ready` and the pull request checks then claim and check for you, and the developer MCP gains `board_claims`, `board_claim` and `board_release`. Start developing lists who is working on what.
