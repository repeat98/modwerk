Rytm base: a stock knob edit of the FX track's hidden words 38 to 41 no longer overwrites the delay's saved TIME. Stock's edit save had no slot for those words and wrote them over TIME, which then came back changed after a power cycle. Both base variants now save such an edit into the kit's own module storage, so it survives a power cycle and TIME stays as set. Nothing in the library edits those words today; this clears the way for modules that will. The base packages are rebuilt, and the Rytm guide says how the guard works.
