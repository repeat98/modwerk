Octatrack: the card firmware builder is retired. Modules reach an Octatrack through the Modwerk base only: synced over USB or, without USB, as one module file on the card (Your Octatrack → Setup → Load from the card). The page no longer builds a whole firmware file with modules in it. Tuner, Stem Rec and Temp Save are paused until each has a version for the base; POLY8, VECTOR, Play Modes and Sidechain Compressor install the version their base package holds. A module that needs the base can now be added in any browser.
