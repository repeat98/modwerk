Analog Rytm MKII: the Modwerk base no longer sets aside a fixed work area for send effects. An effect's delay lines now live in the mod RAM the set leaves free, so a set with a send effect has about 32 KB more room for modules, and PHASER, which needs no work area, starts at once. CHORUS and FLANGER play as before. If a set ever leaves less room than an effect needs, that effect is not listed, and a local build with `scripts/link-image.mjs` says so.
