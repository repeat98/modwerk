Analog Rytm MKII: the Modwerk base no longer sets aside a fixed work area for send effects. An effect's delay lines now live in the mod RAM the set leaves free, so a set with a send effect has up to 32 KB more room for modules (about 16 KB with CHORUS or FLANGER, whose delay lines take the rest), and PHASER, which needs no work area, starts at once. CHORUS and FLANGER play as before. If a set ever leaves less room than an effect needs, that effect is not listed, and a local build with `scripts/link-image.mjs` says so.
