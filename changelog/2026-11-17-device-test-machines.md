SDK (Octatrack): `npm run device:test` and `device:qualify` now place machine packages. Until now they placed only DSP effects: POLY8, FM Synth, VECTOR, Amiga and SYNTIZ went untested, and Analog BD was offered to the FX1 chooser, where it can't appear. A machine now goes onto T1 and T5 through SRC SETUP's machine list, plays, and has its render compared with its CPU price; then it goes onto every track beside the set's effects, and its SRC page knobs are swept. A refusal (CPU FULL, DSP FULL) is reported with a screenshot of the box. A machine renders only on trigs, so run it on a Part with trigs on T1 and T5. The run also saves the Part before it starts (the same bytes), so its closing reload works after a RAM boot, and plays five seconds after each machine goes back, so the next pick is not judged with that machine still counted.
