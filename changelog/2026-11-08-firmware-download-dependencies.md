Development: `npm run firmware:download` now builds Digitakt and Digitone selections that need a dependency folder (Machine Pages, DT Support). It used to look up every planned package in the live release list. Dependencies are not in that list, so it refused SOPHIE, STRING, RAM Machines, Euclidean and CC Names with "Module is unavailable for public downloads". Their packages are still checked against the published catalogue's SHA-256 pins.
